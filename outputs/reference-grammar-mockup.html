2. 여기서 나온 것 셋

① 진짜 범인은 라운드였습니다

자라 0 · 나이키 사실상 0 · 룰루레몬은 버튼만 1000px(완전 알약)이고 나머지 0. 반면 대성마이맥은 10px가 94번. 고급 브랜드는 라운드를 안 쓰거나, 쓰면 완전한 알약까지 갑니다. MONC 현재 토큰은 8·14·20·24px — 전부 그 '어중간한 중간값'입니다. 색을 다 빼도 이게 남으면 여전히 물러 보입니다.

② 무채 ≠ 차가움

룰루레몬은 순수 검정·흰색을 안 씁니다. 먹이 #140F0F(살짝 붉은), 종이가 #FDFDF6(살짝 노란). 숫자로는 무채인데 눈으로는 따뜻합니다. MONC의 아이보리 + 네이비가 정확히 같은 사고라, 대표님 로고는 이미 이 문법 위에 있습니다.

③ 색은 '기능'일 때만 씁니다

나이키의 유채 글자 32회는 전부 세일가 초록·품절 빨강입니다. 장식이 아니라 정보예요. 룰루레몬 1회, 자라 0회. 반대로 대성마이맥은 137회를 강조하려고 씁니다. MONC에서 이 기준을 통과하는 건 '모집 중' 하나뿐입니다.

3. 문법별 5안

각 레퍼런스의 문법(색·라운드·글자 크기 단계·카드 유무)을 MONC 홈 화면에 그대로 옮겼습니다. 맨 왼쪽은 대조군입니다 — 지금 업계 표준이 어떤 모습인지 같이 놓고 봐야 판단이 됩니다. 375px 실물 크기, 가로 스크롤하면 다섯 열이 다 나옵니다.

A · 자라 문법

  • 가장 극단입니다. 색 0, 라운드 0, 라벨 10px. 사진이 좋으면 최고, 아니면 바로 들통납니다.
  • MONC엔 인물 사진 4장이 있어 해볼 만합니다.
  • 약점: 자라는 이미 아는 브랜드라 이게 통합니다. 처음 오는 사람에게 설명이 없으면 불친절해집니다.
  • 약점: 승무원 준비생은 불안해서 오는데 차갑습니다.

B · 룰루레몬 문법

  • 절제하면서 따뜻함을 잃지 않는 유일한 레퍼런스입니다.
  • 라운드 규칙이 명확합니다 — 버튼만 알약, 나머지 전부 0. 애매한 값이 없습니다.
  • 제목이 커서(28~36px) 색 없이도 위계가 섭니다.
  • 약점: 그대로 쓰면 MONC 로고의 네이비가 갈 자리가 없습니다 → D안이 그걸 푼 것입니다.

C · 나이키 문법

  • 글자 크기가 16/14 두 단계뿐이라 화면이 아주 정돈됩니다.
  • 색을 '기능'으로만 씁니다. MONC에서 그 기준을 통과하는 건 '모집 중' 하나입니다.
  • 약점: 순백·순검정이라 사무적입니다. 스포츠 브랜드의 힘이 없으면 밋밋해집니다.
  • 약점: '모집 중' 초록은 MONC 브랜드와 무관한 색입니다. 기능색이라도 하나 늘어나긴 합니다.

D · MONC (추천)

  • 룰루레몬 문법 + 로고 색. 네이비가 곧 먹, 아이보리가 곧 종이입니다.
  • 유채색을 하나도 안 쓰면서 브랜드 색은 화면 전체에 있습니다 — 강조색이 아니라 잉크라서요.
  • 명조 제목만 남겼습니다. 다섯 안 중 유일하게 남의 문법이 아닌 부분이고, 대표님이 이미 쌓아 둔 자산입니다.
  • 7/27 종이 카드는 배경이 아이보리라 살릴 수 있지만, 이 안에서는 라운드 0 규칙 때문에 상자를 뺐습니다 — 채택 시 짚어야 할 지점입니다.

다음에 정할 것 하나. 이번 목업들은 라운드 0 규칙에 맞추려고 7/27에 정하신 레터프레스 종이 카드(상자 + 14px 라운드 + 그림자)를 뺐습니다. 그때 근거("사진만 걸어놓으면 입체감이 없다")는 여전히 유효하지만, 레퍼런스 다섯 곳 중 카드 상자를 쓰는 건 대조군뿐입니다. '종이 카드를 살릴지, 라운드 0으로 갈지'는 색과 별개의 결정이라 따로 봐야 합니다.
