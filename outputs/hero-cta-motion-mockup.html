시작하기 버튼 모션 5안

실제 랜딩 페이지의 창문 히어로를 그대로 재현한 목업입니다. 다섯 가지 방향이 각각 살아 움직이고 있으니, 버튼을 눌러 누름 반응까지 함께 확인해 보세요. 모두 CSS만으로 구현되어 성능 부담이 없습니다.

둥실 플로팅

잔잔함 · 고급감

MONC

새로운 커리어가
시작되는 순간

구름 위에 떠 있는 것처럼 아주 천천히 오르내립니다. 아래 그림자가 함께 커졌다 작아져서 정말 떠 있는 듯한 깊이감이 생겨요.

  • 움직임이 계속되지만 느리고 부드러워서 산만하지 않음
  • "하늘 위" 브랜드 무드와 가장 자연스럽게 어울리는 안
  • 기본값으로 넣어두기 가장 무난한 1순위
적용 CSS 보기
@keyframes float-up {
  0%, 100% { transform: translateY(0); }
  50%      { transform: translateY(-7px); }
}
.cta { animation: float-up 3.2s ease-in-out infinite; }
/* 그림자는 별도 요소로 두고 반대로 scaleX(.78)까지 줄이기 */

MONC

시작되는 순간

말씀하신 방향 그대로예요. 몇 초에 한 번씩 아래로 살짝 눌렸다가 통! 하고 튀어오릅니다. 눌리는 순간 옆으로 퍼지는 젤리 느낌을 줘서 생동감이 있어요.

  • 다섯 안 중 시선을 끄는 힘이 가장 강함 — 전환율 최우선이면 이 안
  • 쉬는 구간(약 2초)을 충분히 둬야 산만해지지 않음
  • 차분한 브랜드 톤과는 살짝 결이 다를 수 있는 점만 고려
적용 CSS 보기
@keyframes bounce-pop {
  0%, 52%   { transform: translateY(0) scale(1, 1); }
  58%       { transform: translateY(6px) scale(1.05, .92); }  /* 눌림 */
  64%       { transform: translateY(-13px) scale(.97, 1.05); } /* 점프 */
  71%       { transform: translateY(0) scale(1.04, .95); }     /* 착지 */
  85%, 100% { transform: translateY(0) scale(1, 1); }
}
.cta { animation: bounce-pop 3.8s ease-in-out infinite;
       transform-origin: center bottom; }
3안

펄스 글로우

차분함 · 신호등 같은 존재감

MONC

새로운 커리어가
시작되는 순간

버튼은 가만히 있고, 네이비 빛이 물결처럼 바깥으로 퍼져 나갑니다. 관제탑 신호나 비콘 같은 항공 무드가 있으면서, 움직임 없이도 시선이 계속 갑니다.

  • 버튼 자체가 안 움직여서 가장 점잖고 안정적인 안
  • 텍스트 가독성에 전혀 영향이 없음
  • 1안(플로팅)과 겹쳐 쓰면 시너지가 좋은 조합형 후보
적용 CSS 보기
@keyframes pulse-ring {
  0%   { box-shadow: 0 0 0 0 rgba(44,74,124,.4); }
  70%  { box-shadow: 0 0 0 16px rgba(44,74,124,0); }
  100% { box-shadow: 0 0 0 0 rgba(44,74,124,0); }
}
.cta { animation: pulse-ring 2.6s cubic-bezier(.4,0,.4,1) infinite; }
/* 기존 그림자는 box-shadow 앞쪽에 쉼표로 같이 유지 */

시작되는 순간

창문으로 들어온 햇빛이 버튼 표면을 스치고 지나가는 반사광입니다. 몇 초에 한 번 사선으로 빛줄기가 지나가요. 명품·항공사 브랜드가 즐겨 쓰는 연출입니다.

  • 버튼이 "만져지는 재질"처럼 보여서 고급감이 가장 큼
  • 움직임이 아니라 빛이라 점잖으면서도 눈에 띔
  • 창문 컨셉(햇빛)과 스토리가 자연스럽게 이어짐

5안

이륙 시그니처

브랜드 시그니처 · 기억에 남는 한 방

MONC

새로운 커리어가
시작되는 순간

몇 초에 한 번, 작은 종이비행기가 버튼 옆에서 이륙해 하늘로 날아갑니다. 버튼도 그 순간 살짝 들리면서 기울어요. "새로운 커리어의 시작 = 이륙"이라는 카피와 정확히 맞물리는 MONC만의 시그니처 모션입니다.

  • 다섯 안 중 가장 기억에 남고, 브랜드 스토리가 담김
  • 주기를 5초 이상으로 길게 둬서 "가끔 일어나는 이벤트"처럼 연출
  • 클릭 시 비행기가 날아가며 페이지 전환하는 연출로 확장 가능
