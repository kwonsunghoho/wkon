레퍼런스 문법을 입힌 4안

2026-08-03 클래스101·메가스터디·무신사·29CM·듀오링고 실제 모바일 화면을 열어 카드 문법을 채집했다. 배치(2×2·4열)와 하단 일정·상태 줄은 오너 확정대로 유지.

채집 기록 — 다섯 곳이 카드에 쓰는 것

클래스101: 큰 썸네일 → 결과를 약속하는 카피형 제목 2줄 → '크리에이터|난이도' 메타 → "일러스트 1위" 랭킹 한 줄(주황 아이콘). 가격은 카드에 없다(구독제).

메가스터디: 카드보다 강사 인물 전면 + 실명 브랜드("현우진의 킬링캠프 시즌1") + 과목 탭 + N·HOT 뱃지. 정보 밀도 최상.

무신사: 랭킹 번호 + '판매 5.5천개' 칩 + 브랜드명 볼드/상품명 회색/할인%·가격 볼드 3단 스택 + "2천명이 보는 중" 실시간 줄. 전부 숫자다.

29CM: 대형 화보 배너(영문 디스플레이 + 국문 카피 한 줄) / 리스트는 브랜드 볼드 + 상품명 + 할인%·가격 + '조건부 무료배송' 태그 칩 + 하트 수.

듀오링고: 아이콘 + 언어명 + "학습자 463만명" 한 줄이 전부. 두꺼운 라운드 테두리.

공통점은 장식이 아니라 숫자로 된 증거 한 줄이다 — 1위·판매량·학습자 수·하트. 지금 우리 카드엔 날짜 말고 숫자가 없다. 그게 밋밋함의 실체다. 아래 4안의 후기·참가 숫자는 전부 예시값 — 채택 시 실데이터(기수·후기 수 등) 연결이 전제(숫자를 꾸며 넣지 않는다).
