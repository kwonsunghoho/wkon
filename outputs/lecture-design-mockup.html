Design Preview

특강, 이렇게 올라가요

어제 만든 특강 시스템의 실제 화면 미리보기예요. 아래 카드와 화면은 전부 예시 데이터이고, 실제로는 관리자 페이지에서 등록한 내용이 그대로 이 모양으로 나타납니다.

0관리자 페이지 '특강' 탭에서 등록제목·날짜·강사·참가비·잔여석
1홈 화면에 카드가 뜸전·후 목소리 섹션 바로 다음
2'특강' 메뉴 = 전체 목록신청 중 → 예정 → 마감 순서
3카드를 누르면 상세 화면그 자리에서 결제·신청까지 끝

새로운 특강이 열리면 여기에서 가장 먼저 알려드려요.

▲ 홈 화면(폰 기준) — 잔여 5석 이하면 '잔여 3석'처럼 항공사 색으로 강조돼요

홈에서는 '맛보기'만

  • 가장 가까운 특강 2개만 뜹니다. 홈이 이미 긴 편이라 여기서 목록을 다 펼치면 아래 섹션들이 밀려요.
  • 등록된 특강이 하나도 없으면 카드 자리가 조용히 비고 안내 문구만 남아요 — 빈 네모나 오류 메시지가 뜨지 않습니다.
  • 위치는 '전·후 목소리' 섹션 바로 다음. 목소리 증거를 듣고 마음이 움직인 자리에서 특강을 만나게 한 배치예요.
  • 배경이 한 톤 밝은 건 홈의 밝고-어둡고 리듬을 지키기 위한 것이고, 제목이 왼쪽에 붙은 것도 '카드가 놓이는 섹션은 왼쪽 정렬'이라는 홈 전체 규칙을 따른 거예요.

관리자 페이지에서 적는 것

  • 제목 · 한 줄 설명 · 소개글
  • 항공사(고르면 색과 영문명이 자동으로 붙어요)
  • 진행 날짜 · 시간/장소 · 강사
  • 신청 받는 기간(이 기간이 지나면 자동으로 마감)
  • 참가비(0원이면 무료 특강) · 정원 · 잔여석
  • '이런 걸 얻어가요' 항목들

'특강' 메뉴 — 전체 목록 화면

메뉴의 '특강'을 누르면 나오는 화면이에요. 신청 중 → 신청 예정 → 마감 순서로 자동 정렬되고, 마감·품절된 특강은 흐리게 남아 "이런 것도 했었구나"를 보여줍니다.

▲ 특강 목록(폰 기준) — 다섯 가지 상태(유료·무료·기본색·예정·마감)를 한 화면에 담았어요

카드 디자인 규칙 — "일곱 항공사가 한 가족처럼"

  • 카드 윗부분(아이보리색)은 모든 카드가 똑같아요. 항공사마다 바뀌는 건 딱 두 가지 — 영문 항공사명 색과 밑줄 색.
  • 한글 제목은 항공사와 상관없이 항상 짙은 네이비. 그래서 어떤 카드가 나란히 서도 차분하게 한 세트로 보여요.
  • 항공사 로고 이미지는 안 써요(허락 문제도 있고, 로고가 섞이면 조잡해져요). 영문 사명을 글자로만 조판해요.
  • 오른쪽 위 뱃지: 무료 = 옅은 초록, 유료 = 금액이 그대로 적힌 옅은 네이비.
  • 잔여석이 5석 이하로 내려가면 그 글자만 항공사 색으로 강조 — 은근한 마감 임박 신호예요.
  • 그림자·번쩍임·기울임 효과는 일부러 뺐어요. 마우스를 올리면 테두리만 살짝 진해집니다.

상세 화면 — 이 안에서 신청·결제까지 끝

카드를 누르면 나오는 화면이에요. 특강마다 페이지를 새로 만드는 게 아니라, 관리자 페이지에 적은 내용이 이 틀에 자동으로 채워져요. 아래로 내리면 신청 폼이 있고, 토스 결제 또는 계좌이체로 그 자리에서 신청이 끝납니다.

특강 소개

대한항공 최종면접은 답을 잘하는 사람이 아니라, 함께 일하고 싶은 사람을 뽑는 자리예요.

면접관이 실제로 체크하는 항목을 기준으로, 내 답변이 어디서 점수를 잃는지 그 자리에서 짚어드립니다.

이런 걸 얻어가요

  • 최종면접 평가표, 실제로 뭘 보는지
  • 내 답변 1분 시연 + 즉석 피드백
  • 합격생들이 마지막 일주일에 한 것

▲ 상세 화면(폰 기준) — 실제 폰에서는 한 화면씩 스크롤되지만, 여기선 전체를 펼쳐 놨어요.
맨 아래 '신청하기' 바는 스크롤 내내 화면에 붙어 있다가, 누르면 신청 폼으로 데려갑니다.

참가비에 따라 버튼이 자동으로 바뀌어요

  • 유료 특강 — 파란 토스 결제 버튼 + 계좌이체 버튼, 두 가지 길이 떠요. 계좌이체를 누르면 입금 계좌 안내가 화면 아래에서 올라옵니다.
  • 무료 특강 — 결제 없이 주황 버튼 하나로 바로 접수돼요.
  • 마감·품절 — 폼이 사라지고 "신청이 마감된 특강이에요" 안내만 남아요.
  • 토스 결제는 금액을 서버가 한 번 더 검사해서, 화면을 조작해 싸게 결제하는 걸 막아요.
  • 신청자는 챌린지 신청자와 같은 관리자 명단에 📚 표시로 쌓여요 — 보는 곳이 늘어나지 않아요.
