저장소가 중심, AI킬러는
그 위에서 도는 기능

화면 10개 · 4단계. 저장소(목록·추가) → 답변 상세(검사 이력) → KILL AI 입력 → 첨삭·충전(유료). 항공사 버튼과 '고르기'는 실제로 눌러 볼 수 있다.

앞 목업은 "답변이 없으면 소재 발굴로 보낸다"고 했는데 그게 틀렸다. 소재 발굴은 소재를 발굴하는 곳이지 답변을 넣는 관문이 아니다. 바로 답변만 쓰고 싶은 학생의 길을 막으면 안 된다.

새로 잡은 규칙

  1. 저장소에 글을 넣는 것은 언제나 무료·무제한. 검사 횟수와 무관하다
  2. 과금 단위는 횟수가 아니라 답변 1개 = 크레딧 1개. 한 답변은 2회까지 검사한다 — 고치고 다시 확인하는 게 이 도구의 핵심 루프라 재검사에 매번 돈을 받으면 도구가 반쪽이 된다 (오너: 한시적으로 2회, 나중에 1회. 상수 하나로 조절)
  3. 유료 사용자 = 아무 글이나 검사하고, 검사한 글은 저장소에 자동으로 들어간다
  4. 검사 이력은 답변마다 쌓이고 언제든 다시 꺼내 본다(한 답변에 여러 번)
  5. 저장소에 검색창 + 질문 유형 구분. 지금은 자유 글에 유형이 없어 분류가 안 된다
  6. 무료는 방향만, 유료는 실제 첨삭 — 아래 마지막 절

화면 4 · 유료

첨삭 — 검사가 진단이면 이건 처방

2026-07-25 오너 확정. 무료는 방향만, 유료는 실제로 고쳐 준다.

왜 이게 'AI 공장'이 아닌가(오너 논거): 학생들은 이미 AI로 답변을 쓴다 — 그래서 AI킬러가 필요한 것이다. 첨삭이 하는 일은 그 반대 방향이다. AI가 쓴 밋밋한 글을 합격자 자료를 기준 삼아, 그 학생의 개인 소재를 최대한 살려서 사람이 쓴 글로 되돌린다. 내용은 학생 것에서 나오고 레퍼런스는 문체·구조의 잣대로만 쓰인다. 그래서 결과가 서로 비슷해지지 않는다.

⚠️ 화면에서는 '합격자 자료'가 아니라 '연구진이 보는 기준'으로 말한다(2026-07-25 오너 확정). 값이 읽히려면 무엇과 비교되느냐가 먼저 정해져야 한다 — 'AI 검사 도구'로 읽히면 ChatGPT(월 3만 원 무제한)와 비교돼 만 원도 비싸 보이고, '연구진 기준의 첨삭'으로 읽히면 학원 첨삭(문항당 2~5만 원)과 비교돼 파격이 된다. 몬크의 자산이 연구진과 합격자 자료인 이상 후자로 서야 한다.

⚠️ 대신 코드에서 반드시 막아야 하는 것 하나 — 원문에 개인 소재가 없으면 AI는 없는 경험을 지어낸다. 그건 첨삭이 아니라 허위 자소서고, 면접장에서 학생이 무너진다. 그래서 소재가 부족하면 첨삭을 시작하지 않고 되묻는다(오른쪽 화면).

답변 상세 + 이력 검사 이력 목록 + 지난 결과 다시 열기. 테이블은 이미 1:N으로 준비돼 있다 없음
검색 · 유형 필터 검색창·칩은 이미 있다. 자유 글이 분류에 잡히도록 고치고 title을 조회에 넣는다 없음
AI킬러 자동 저장 붙여넣기 검사 시 answers에 저장하고 answer_id로 잇는다 없음
마이페이지 카드 답변노트 카드도 같은 규칙으로(두 곳을 같이 고쳐야 한다 — 한쪽만 고치면 제목이 빈다) 없음
크레딧 차등 + 답변 단위 지금 원장은 '검사 1회 = 1차감'이다. 도구별 단가(소재 1 / 킬러 3 / 첨삭 5)를 넣고, credit_ledger.ref를 검사 id가 아니라 answer id로 잡는다 — 그러면 같은 답변 재검사가 자연히 무차감이 된다(2회 상한은 상수 MAX_RECHECK). 무료 한도는 하루·주 단위 리셋이라 원장에 지급 이력을 남기고 기간으로 센다 SQL 1건
충전 팩 · 무료 잠금 체험 5,000/14 · 기본 10,000/30 · 집중 30,000/100. 원장에 free/paid 구분을 넣어 첨삭은 유료 크레딧만 쓰게 한다 — 이 잠금이 수익의 전부라 빼면 아무도 충전하지 않는다 SQL에 포함

확정된 것 — 그대로 구현

  • 크레딧 차등: 소재 발굴 2 / KILL AI 3 / 첨삭 10
  • 가격: 만원 30크레딧(체험 5천/14 · 집중 3만/100). 자소서 1문항 = 18크레딧
  • 무료: 하루 5크레딧, 쌓이지 않고 리셋. 첨삭은 충전 크레딧으로만
  • 포지셔닝: '연구진이 보는 기준' — 학원 첨삭과 비교되게 한다
  • 한 답변은 2회까지 무차감 재검사(나중에 1회로 — 상수 하나)
  • 저장은 무제한 무료 · 붙여넣기 검사는 자동으로 저장소에 저장
  • 무료는 방향만, 유료는 실제 첨삭 — 사실은 원문에서만, 소재 없으면 되묻기
  • 지망 항공사에 '만능' 추가(어디에나 쓰는 답변) — '아직 안 정했어요'와 다른 값

아직 안 정한 것 둘

  • 소재 발굴을 1크레딧으로 돌릴지. 지금은 완전 무료라 있던 게 없어지는 변경이다. 무료 한도(하루 1·주 5)를 킬러 전용으로 둘지, 소재 발굴까지 같은 지갑에서 쓰게 할지
  • 붙여넣기 자동 저장분을 지울 수 있게 할지. 남의 글·연습 글까지 쌓이면 저장소가 지저분해진다 — 기본 저장 + 원할 때 지우기를 권한다
