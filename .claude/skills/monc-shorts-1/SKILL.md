# 몬크 숏츠1번

확정된 글꼴·좌표를 유지하고 영상별 발화와 설명 내용만 바꿔라. 이 스킬은 현재 프로젝트용이며 ChatGPT 개인 스킬 목록 설치와 구분하라.

## 원장과 실행 파일

- 픽셀 설정과 글꼴은 `assets/style.json`, `assets/Pretendard-Bold.ttf`를 원장으로 사용하라.
- 자막 마스크의 빈 여백을 제거한 실제 글자 영역을 기준으로 배치하라. 본문은 Pillow 90px·자간 -1px이며 실제 한글 높이는 약 80px이다. ASS나 편집기의 90pt로 대체하지 마라.
- `scripts/render.py`를 사용하라. 매번 비슷한 새 렌더러를 만들거나 설정값을 바꾸지 마라.
- 입력 스키마·실행 예시·검수 기준은 [제작 절차](references/workflow.md)를 읽어라.

## 절차

1. 현재 요청의 원본 영상을 확인하라. 연결된 파일 목록과 대조하고, 최신 영상이 이전 작업의 원본이면 그 사실을 짧게 밝히라. 영상이 없다고 추측하지 마라.
2. 영상 길이·해상도·음성 유무를 확인하고 발화를 전사하라. 발화 의미·경험·성과를 추가하지 마라. 원본을 임의로 줄이거나 음악·효과음·새 장면을 추가하지 마라.
3. 발화를 의미 단위로 나눈 `cues`와 영상별 `intro`, `labels`, `cards` 계획 JSON을 작업용 폴더에 작성하라. 실제 원본·음성·학생 정보·수강생 문장은 저장소에 넣지 마라.
4. 번들 글꼴과 Pillow를 확인하고 `--preview-only`로 인트로·일반 설명·카드·마무리를 375px에서 확인하라. 얼굴과 입을 가리지 않도록 영상 구도를 먼저 조정하고 자막 좌표는 유지하라. 이전 목소리 영상의 위로 230px 이동값을 모든 새 영상에 맹목적으로 복사하지 마라.
5. 본문 2줄·900px 제한에 걸리면 타임코드와 줄바꿈을 고쳐라. 폰트를 줄이거나 세 줄로 늘려 통과시키지 마라. 카드는 하나의 가로 박스를 유지하라.
6. 전체 영상으로 출력하고 실제 MP4의 대표 프레임과 끝부분, 음성 보존을 확인하라. 최종 영상은 요청의 저장 규칙에 따라 제공하라. 프로젝트 안에는 원본·렌더 결과를 저장하지 마라.

## 고정 규칙

- 일반 본문: (74,1292), 카드 아래 본문: (74,1360), 줄 시작점 간격 104px.
- 라벨: (72,1208), 높이 48px. 카드와 동시에 띄우지 마라.
- 설명 카드: (70,1024)~(936,1258). 제목·구분선·두 열·가는 화살표 구조를 유지하라.
- 본문은 흰색을 유지하라. 파랑은 인트로 밑줄·카드 제목·화살표에 사용하라.
- 큰 상단 배너·세 칸 타일·두꺼운 외곽선·본문 교체 페이드를 추가하지 마라.
- 상단은 MONC와 면접 합격 치트키만 보이게 하라. 숨김 구분문자는 글자 간격을 보존하기 위한 자리이며, 햄버거·줄무늬·깨진 글리프로 그리지 마라.
- 얼굴 형상·피부·음성을 생성하거나 바꾸지 마라. 배경 그라데이션 아래에도 원본 옷과 손의 질감을 남겨라.
- 공개 저장소에 비공개 교육 자료, 영상별 실제 대본, 원본 파일, 파일 접근 토큰, 로컬 절대 경로를 넣지 마라.
