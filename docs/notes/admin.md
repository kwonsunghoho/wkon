### admin.html — 2단 네비 개편 (2026-07-30 · 오너 "기능 나열만 있고 효율적인 동선이 아니다")
탭 11개 한 줄 나열을 **그룹 3개 × 2단 네비**로 재편. 1줄 = 그룹(언더라인 탭), 2줄 = 그 그룹의 화면(알약 칩) — 신청자 현황 종류 필터와 같은 문법.
- **그룹 구성(오너 사용 빈도 기준 — 매일 보는 것이 '운영')**: 운영(오늘·신청자 현황·오픈 알림·회원 관리·크레딧) / 상품(챌린지·특강·답변 프로그램) / 콘텐츠(후기 관리·감점 사전·소재 문제). ⚠️ **탭을 추가하면 어느 그룹인지부터 정할 것** — 맨 뒤에 이어붙이면 개편 전으로 돌아간다.
- **탭 이름 변경**: '모집일정'→'챌린지', '기출문제'→'소재 문제'(소재발굴 도구에 나가는 오늘의 문제 — 답변 프로그램의 '기출 은행'과 이름이 겹쳐 혼동되던 것). '홈 커뮤니티' 탭은 삭제(위 커뮤니티/후기 절 참조).
- **⚠️ 기출 은행의 자리는 '상품 > 답변 프로그램' 서브탭이 맞다(2026-07-30 오너 확정).** 개편 직후 오너가 "기출 넣고 세팅하는 게 콘텐츠에서 빠졌다"고 물었다 — 사라진 게 아니라 상품 탭 안에 있는 것. 콘텐츠 그룹 독립 탭으로 승격하는 안을 제시했으나 **오너가 지금 위치 유지를 선택**(기출 등록과 일차 배치가 한 화면이라 조립 작업이 편하다). 같은 질문이 또 나오면 위치 안내가 답이지 구조 변경이 아니다.
- **첫 화면 = '오늘' 대시보드**(`panel-today`): 입금 확인 필요(계좌이체 미입금·환불 제외) · 오픈 알림 연락 전 · 검수 대기(→review-desk.html 링크) · 오늘 신청 · 오늘 새 회원 + 최근 신청 5건. 숫자를 누르면 해당 탭으로(`activateTab()` — 탭 버튼 클릭 핸들러가 그룹 줄까지 동기화하므로 어디서 불러도 일관). ⚠️ **`loadToday()`는 초기화 시퀀스 맨 끝** — 카드가 `_apps`/`_wl`/`members`를 재사용해서 `loadApplications`/`loadWaitlist`를 `await`한 뒤에 돈다(추가 조회는 answer_sessions count 하나 — 미적용 환경은 try/catch로 0 표시).
- **⚠️ `#tabs`를 켤 때 `style.display = 'block'`** — 구 `'flex'`를 그대로 두면 그룹 줄과 알약 줄이 **가로로 눕는다**(실측으로 잡은 회귀 — 인라인 스타일이라 CSS로 못 이긴다).
- **답변 프로그램 탭 안은 서브탭 6개**(`.ap-st`/`.ap-sec`: 기출 은행·프로그램·이용권·연구원·수정 코드·진행률) — 기출 89개 시점부터 6절 세로 나열이 한 스크롤에 안 담겨 분리. ⚠️ 서브탭에 `.tabbtn` 클래스를 쓰지 말 것(initTabs가 tabbtn 전부에 패널 전환을 건다). `.ap-sec[hidden]{display:none}` 가드 유지.
- **모바일(<760px)**: 알약 줄은 `nowrap + overflow-x` 1줄 스크롤 — wrap으로 두면 스티키 탭바가 150px(화면 1/4)를 먹는다(실측 116px로 축소). 터치는 전 버튼 44px+(9대 원칙 2).
- 검증법: 로그인 게이트라 프리뷰로 바로 못 본다 — `requireAdmin`을 목으로 바꾼 사본을 서버 루트에 두고 확인(이 파일은 커밋 금지). ⚠️ 프리뷰 서버 cwd가 워크트리일 수 있다 — repo 루트 파일을 고쳤는데 반영이 안 보이면 `preview_list`로 서빙 디렉토리부터 확인할 것.
