### 강조는 딱 세 자리 — 더 늘리지 말 것

1. **01 = 틴트 '판'**(`.is-feat`). 목차에서 유일하게 면을 가진 행이라 헤어라인 리듬을 한 번만 깬다. 번호는 네이비 도장, 이름 22px.
2. **06 = 우편 '소인'**(`.pm`). 매일 오는 것에 찍는 도장이라 기출과 뜻이 맞는다. 점선 리더 위에 겹쳐 찍힌다.
3. **03 = '처음 추천' 배지**(`.tg`). 룰렛이 돌면 '처음이라면' 코스가 화면에 없는 순간이 생기므로, 처음 온 사람의 기준점을 여기 상시로 남긴다.

02·04·05 는 조용한 행으로 둔다 — **조용한 행이 있어야 강조가 강조로 읽힌다.**

- ⚠️ **'인기' 같은 근거 없는 표시 금지**(2026-07-31 오너 기각 — 이용 데이터가 쌓이기 전엔 참이 아니다). 'NEW' 도 같은 이유로 뺐다. 데이터가 생기면 그때 단다.
- ⚠️ **카드에 권한 알약 배지를 달지 말 것**(2026-07-25 오너 "이거 다 빼"). 구 `.bf-badge`(누구나/수강생 전용/회원 전용)는 4장 중 3장이 같은 회색 알약이라 구분에 기여하지 않았고 11.5px 로 가독성 하한에도 미달이었다. 권한 안내는 각 도구 페이지의 로그인·동의 게이트가 담당.
- ⚠️ **'첫 1회 무료' 같은 회원별 상태 문구 금지** — 이미 쓴 학생에게 거짓이 된다. 무료 안내는 각 도구 페이지가 잔액을 읽어 말한다.

### 추천 코스 룰렛(`.d-route`)

공항 전광판이 다음 편으로 넘어가듯 코스 4개가 **3.8초마다 위로 굴러가며** 교체된다. 카드 탭 = 즉시 다음, 점 = 해당 코스로 점프(점은 6px 이지만 버튼 표적은 24×30px). 탭이 백그라운드면 돌지 않는다.

코스(전부 **지금도 참인 경로만**): ① 처음이라면 03→04→05 ② 매일 5분 02→06→01 ③ 쓴 답변이 있다면 05→04→01 ④ 면접이 코앞이라면 01→02→06. **첫 코스는 항상 '처음이라면'.**

- `prefers-reduced-motion: reduce` 면 자동 회전을 끄고 탭으로만 넘어간다(굴림 애니메이션도 없음).
- 화면 낭독기에 3.8초마다 알리지 않는다(소음). 목차 6줄이 본문에 그대로 있어 **룰렛은 지름길이지 유일한 길이 아니다** — 이 전제를 깨는 변경(정보를 룰렛에만 두기)은 금지.

### 실측값 — 바꾸기 전에 읽을 것(375px 기준)

- **설명줄 `.ix-desc` = `var(--fs-body-sm, 15px)`/500/행간 1.62.** 2026-07-25 오너 확정값(구 14px/400 → "서브타이틀이 너무 안 읽힌다", 목업 4안 중 B 선택). 명조 19px 이름 밑에 캡션 크기가 앉으면 위계가 무너진다 — 목차형으로 바뀌어도 같은 관계라 값을 그대로 가져왔다. **내리지 말 것.** ⚠️ `var()` 폴백 15px 필수 — 이 CSS 는 HTML 인라인이고 tokens.css 는 별도 파일이라 '새 HTML + 캐시된 구 tokens.css' 조합에서 선언이 무효가 되어 16px 로 튄다(실측).
- **번호 칸 `.ix-no` = 44px + `white-space:nowrap`.** 36px 이면 `NEWS`·`DAILY` 가 두 줄로 깨진다(10.5px + letter-spacing .13em 에서 DAILY 가 39px). 코드를 늘리면 다시 잴 것.
- **`.is-daily .ix-desc` 의 `padding-right: 78px` 는 소인 자리다.** 도장이 `absolute` 라 설명 텍스트가 자동으로 안 밀린다(구 `.bf-desc`·news `.nw-link` 와 같은 함정). 62px 이면 **설명 첫 줄이 도장 원을 6px 밟는다**(원 중심에서 26px < 반지름 28.5px). ⚠️ 계산은 원이 가장 넓은 지점이 아니라 **첫 줄 높이(y)에서의 원 폭**으로 해야 한다 — 그 자리 폭이 좌우 18px 라 여백은 76px 이상. **문구를 늘리면 이 여백을 다시 잴 것.**
- `.ix-wrap { max-width: 600px }` — 데스크톱에서 줄이 너무 길어지지 않게. `.ix-desc` 의 `text-wrap: pretty` 는 데스크톱(줄 폭 420px)에서 마지막 줄에 한 단어만 남던 것 방지.
