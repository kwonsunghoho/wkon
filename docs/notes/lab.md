## 구조 — 허브는 카드 두 장(오너 확정, 되돌리지 말 것)

오너: **"간결하게 연구실 / 연구진 이렇게 두개 카드만 딱 나와야지 그게 허브 아니냐고."**

- `lab.html`(허브) = 히어로 + **카드 두 장**: 연구실 → `lab-archive.html` / 연구진 → `researchers.html`. 허브에 목록·연구진 임베드를 다시 넣지 말 것.
- **허브 카드 표면은 ②안 '콘솔'(같은 날 확정 — "뭔가 밋밋하지않냐? 연구실인데" → 3안 목업 `outputs/lab-hub-flavor-mockup.html` 중 "2안이 좋어보인다")**: 연구실 카드 = 다크 네이비 콘솔(#1E4079→#142C52) + 서가 목차 5줄(점선 리더, lab-archive 와 같은 순서·수치) + '연구 진행 중' 라이브 점 + 흰 알약 화살표(다크 위 CTA 규칙). 연구진 카드 = 레터프레스 종이 + **얼굴 6개**(`researchers-data.js` 에서 JS 생성 — 인원수도 배열 길이로 갱신, 페이지에 복사 금지). 기각된 ①색인(종이만)·③연구노트(모눈+탭)는 목업 파일에 기록.
- `lab-archive.html`(원장) = 현황 스트립 + 서가 카드 5장. 화면 글자는 '연구실'.
- 연구진 소개는 `researchers.html` 단독(허브 카드·nav 목차로 진입 + apply.html 링크). 연구원 데이터는 `researchers-data.js` 단일 원본 — 페이지에 배열 복사 금지.
- nav: 탭 '연구실'(카테고리, 두 번 누르면 허브 lab.html) → 목차 두 줄 = 허브 카드와 1:1(연구실→lab-archive / 연구진→researchers). **탭을 연구실·연구진 두 개로 분리하는 안은 기각**(폭 초과 실측·소개 페이지 급 상승·허브 무의미 — 사유·경과는 nav.md).

같은 날 오전의 중간 형태들(원장+연구진 한 페이지, 연구진 2단 카드 임베드, 드롭다운 '연구진 소개' 항목)은 전부 이 구조로 대체됐다. 결정이 하루에 여러 번 뒤집혔으니 **이 절이 최종형이다.**

## 원장(lab-archive.html) 디자인 — 서가 카드 5장

2026-07-31 오후 오너 지시로 **헤어라인 원장 → 카드형 전환**("연구실 카드 누르면 나오는 원장 페이지도 카드형으로 바꿔줘라"). **'상자(테두리·그림자) 금지' 규칙은 이때 폐지.** 헤어라인 확정본은 `outputs/lab-hub-mockup.html`(v1~v3-c 결정 경과는 그 머리 주석) · `outputs/lab-cards-mockup.html`(4안 비교)에 기록으로만 남는다. 재설계 3안(`outputs/lab-hub-redesign-mockup.html`)은 보류 그대로.

- 카드는 허브(lab.html)와 같은 **레터프레스 종이 언어**(#FCF9F1→#F3EEE1 + 안쪽 흰 하이라이트) — 새 색 없음.
- 카드 구성: 색인 + 이름·설명 + 오른쪽 계기 열(누적 수→증감, 폭 60px) + 발치(점선 구분선 위 최신 태그·항목·날짜 — 허브 `hub-meta` 와 같은 점선). 숫자는 전부 `tabular-nums`.
- **축적 막대(8주 스파크라인)는 오너 지시로 제거** — 되살리지 말 것.
- 태그 활자 12px(목업 11.5px 는 9대원칙 하한 미달이라 올림).

## 데이터 — 지금은 전부 예시값

**화면 숫자는 DB 에서 실제로 셀 수 있는 값만 쓴다는 게 전제**(신뢰가 콘셉트). 자료 테이블이 아직 없어 원장 숫자·허브 '자료 180건'은 예시고 **foot-note 가 밝힌다.** 데이터 연결 시 예시값·foot-note 를 같이 걷어낸다. 허브의 '연구원 6명'은 실제 값(`researchers-data.js` 배열 길이).

## 하위 페이지 — 아직 없음

서가 카드 5장은 도착 페이지가 없어 **href 없는 `<a>`(비활성)**. 페이지가 생기면 href 를 단다 — 호버 리프트·포커스 링이 `[href]` 게이트라 그때 살아난다. nav `LAB_SUB` 에도 한 줄씩 추가. 죽은 `href="#"` 금지.
