## 확정 디자인 — 헤어라인 원장 + 연구진 합본

결정 경과(목업 머리 주석에도 있음): v1 상세 나열형 기각("허브인데 상세페이지") → v2 요약 카드 통과했으나 "밋밋" → v3-a 소품 콘셉트 기각("통일감 없음") → v3-c 연구실 감도 4안 중 **① 연구 대장(헤어라인 원장) + ② 관측 패널 합본** 확정.

- **상자(카드 테두리·그림자) 금지** — 활자·헤어라인·숫자만으로 '연구실' 감도를 만든다. 상자를 되살리면 승준노트 허브와 같은 화면이 된다.
- **축적 막대(8주 스파크라인)는 오너 지시로 제거(2026-07-31)** — 되살리지 말 것.
- 원장 행 구성: 색인 번호 + 이름·설명 + 오른쪽 계기 열(누적 수 → 증감) + foot(최신 태그 · 최신 항목 · 날짜). 숫자는 전부 `tabular-nums`.
- `.lg-foot` padding-left 33px = 색인 폭 + gap(제목 왼쪽선 정렬값). 색인 활자를 바꾸면 같이 본다.
- 목업 대비 의도적 수정 1건: `.lg-tag` 활자 11.5px → **12px**(9대원칙 1번 하한).

## 데이터 — 지금은 전부 예시값

**화면 숫자는 DB 에서 실제로 셀 수 있는 값만 쓴다는 게 이 화면의 전제**(신뢰가 콘셉트라 꾸민 지표는 금방 들통난다). 하위 자료 테이블이 아직 없어 현재는 예시값이고, **하단 foot-note 가 예시임을 밝힌다.** 데이터 연결 시 예시값과 foot-note 를 같이 걷어낸다.

## 하위 페이지 — 아직 없음

원장 5행(자료실·영상관·기출·리포트·캘린더)은 도착 페이지가 없어 **href 없는 `<a>`(비활성)** 상태. 페이지가 생기면 href 를 달면 된다(`.lg-row:focus-visible` 규칙은 그때 살아난다). 죽은 `href="#"` 를 달지 말 것.

## 연구진 섹션

- 데이터는 **`researchers-data.js`(`window.MONC_RESEARCHERS`) 공유** — researchers.html 과 단일 원본. 페이지에 배열 복사 금지.
- 렌더러는 페이지별: lab 은 모바일 단일 컬럼·지표 정적 표기(카운트업 없음), researchers.html 은 기존 그대로(카운트업 있음).
- **프로필 박스는 researchers.html 좁은 화면 규격(2026-07-31 오너 — "사진이 너무 커서 부담")**: 사진 블록 `.mi-figure` **340px 상한 + 가운데 정렬**, 정방형, **필터 없음**(목업의 grayscale 필터·패널 꽉 찬 사진은 폐기 — 되살리면 사진이 다시 커진다). 제목 '핵심 이력', 버튼 '전체 이력 보기/접기'로 researchers 와 동일.
- ⚠️ `.mi-extra[hidden]{display:none}` 보강 필수 — 목록이 `display:flex` 라 이 규칙이 없으면 hidden 이 안 먹혀 '전체 이력'이 항상 펼쳐져 보인다(초기 구현에서 실제로 밟은 버그, researchers.html 도 같은 보강을 갖고 있다).
- 고은지 사진 크롭 예외(`object-position:60% 50%`)는 두 페이지 공통.
- 참고: 프리뷰(숨김 탭)에서 `getComputedStyle().filter` 가 없는 grayscale 값을 보고하는 아티팩트가 있다 — 필터 유무는 소스 grep 으로 판정할 것(researchers.html 교차 측정으로 확인됨).
