# 몬크 연구실 (lab.html 허브 · lab-archive.html 원장)

> 2026-07-31 신설·같은 날 구조 확정. 항공사 자료실·영상관·기출문제·현장 리포트·채용 캘린더 + 연구진.

## 구조 — 허브는 카드 두 장(오너 확정, 되돌리지 말 것)

오너: **"간결하게 연구실 / 연구진 이렇게 두개 카드만 딱 나와야지 그게 허브 아니냐고."**

- `lab.html`(허브) = 히어로 + **카드 두 장**: 연구실 → `lab-archive.html` / 연구진 → `researchers.html`. 카드는 챌린지 허브의 레터프레스 종이 언어. 허브에 목록·연구진 임베드를 다시 넣지 말 것.
- `lab-archive.html`(원장) = 현황 스트립 + 서가 5행(헤어라인 원장). 화면 글자는 '연구실'.
- 연구진 소개는 `researchers.html` 단독(허브 카드로 진입 + apply.html 링크). 연구원 데이터는 `researchers-data.js` 단일 원본 — 페이지에 배열 복사 금지.
- nav: 탭 '연구실'(카테고리) → 목차 '연구실' 한 줄 → lab.html. 상세·폭 실측은 nav.md.

같은 날 오전의 중간 형태들(원장+연구진 한 페이지, 연구진 2단 카드 임베드, 드롭다운 '연구진 소개' 항목)은 전부 이 구조로 대체됐다. 결정이 하루에 여러 번 뒤집혔으니 **이 절이 최종형이다.**

## 원장(lab-archive.html) 디자인 — 헤어라인 원장

원본 목업: `outputs/lab-hub-mockup.html`(확정본, v1~v3-c 결정 경과는 그 머리 주석) · `outputs/lab-cards-mockup.html`(4안 비교). 재설계 3안(`outputs/lab-hub-redesign-mockup.html`)은 '허브 = 두 카드' 지시가 나오며 **보류** — 서가 표현을 다시 논의할 때 꺼낸다.

- **상자(카드 테두리·그림자) 금지** — 활자·헤어라인·숫자만으로 만든다.
- **축적 막대(8주 스파크라인)는 오너 지시로 제거** — 되살리지 말 것.
- 원장 행: 색인 + 이름·설명 + 오른쪽 계기 열(누적 수→증감) + foot(최신 태그·항목·날짜). 숫자는 전부 `tabular-nums`. `.lg-foot` padding-left 33px = 색인 폭 + gap(정렬값).
- 태그 활자 12px(목업 11.5px 는 9대원칙 하한 미달이라 올림).

## 데이터 — 지금은 전부 예시값

**화면 숫자는 DB 에서 실제로 셀 수 있는 값만 쓴다는 게 전제**(신뢰가 콘셉트). 자료 테이블이 아직 없어 원장 숫자·허브 '자료 180건'은 예시고 **foot-note 가 밝힌다.** 데이터 연결 시 예시값·foot-note 를 같이 걷어낸다. 허브의 '연구원 6명'은 실제 값(`researchers-data.js` 배열 길이).

## 하위 페이지 — 아직 없음

원장 5행은 도착 페이지가 없어 **href 없는 `<a>`(비활성)**. 페이지가 생기면 href 를 달고(`.lg-row:focus-visible` 이 그때 살아난다), nav `LAB_SUB` 에도 한 줄씩 추가한다. 죽은 `href="#"` 금지.
