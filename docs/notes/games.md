# 역량검사 게임 연습(games.html) — 상세 기록

> 2026-08-24 신설. 매 작업 공통 규칙은 CLAUDE.md 에 있고, 이 문서는 이 기능을 고칠 때 읽는다.

## 무엇인가 · 왜 만들었나

항공사 채용 전형에 AI역량검사(게임형)가 퍼지고 있어, 그 **게임 유형을 미리 손에 익히는 무료 연습장**이다.

- 2026-08-24 조사에서 확인한 사실: 제주항공은 자인원 역검 전용 응시 도메인(`jejuair.acca.ai`)이 실존, 파라타항공(구 플라이강원)도 동일(`parataair.acca.ai`). 티웨이(2026-10 트리니티항공으로 사명 변경 예정)는 2026-07 채용 전형에 '서류·역량검사·영상면접' 명시, 에어부산은 2025-07 채용부터 AI역량검사 신규 도입 보도, 진에어는 전형에 AI역량검사(1차 면접 뒤) 포함. **티웨이·에어부산·진에어의 검사 업체는 미확정** — 수강생 응시 안내 링크가 `*.acca.ai` 인지로 확정한다.
- **승무원 전형은 7종만 본다(2026-08-25 오너 확정)** — "승무원은 7개만 하거든. 고양이 술래잡기랑 마법약 만들기는 안 한다. 도형 순서 기억은 2-back 이랑 중복." 그래서 **고양이 술래잡기·마법약 만들기·도형 순서 기억은 만들었다가 제거했다 — 다시 넣지 말 것**(코드 이력은 git — 커밋 121b405 이전).
- 오너 확정: **무료, 결제·크레딧 없음.** 순수 클라이언트 게임이라 제공 원가가 0이다(서버·AI 호출 없음) — 유료화하려면 오너 결정부터.

## 지켜야 하는 선(법적 — 완화 금지)

1. **전부 자체 제작이다.** 잡다(자인원)의 화면·그래픽·캐릭터·문구·사운드를 가져오지 않는다(저작권). 게임 '유형'(도형 회전·순서 기억 같은 표준 인지과제)은 아이디어라 자유지만, **검사 전체 구성을 통째로 똑같이 재현하는 것도 피한다**(2019 대법원 팜히어로사가 판례 — 규칙 조합의 복제는 침해가 될 수 있다).
2. **"잡다"·"역검"을 서비스 이름처럼 쓰지 않는다.** 화면 이름은 '역량검사 게임 연습'. 개발사 언급은 고지문의 "자인원·잡다와 무관" 한 곳뿐 — 설명적 사용만.
3. **페이지 하단 고지(`.gm-note`) 삭제 금지**: 자체 도구·개발사와 무관·실제 검사와 다를 수 있음·실전은 PC 응시. 이 네 가지가 오인(공식 제휴로 보임)과 과신(이것만 하면 된다)을 막는다.
4. 실제 검사 화면 캡처를 레포·페이지에 싣지 않는다.
5. **허브는 tools.html 격자 문법이다**(2026-08-25 오너 "우리 결이랑 맞춰" — 일반 카드 격자는 바이브코딩 냄새로 기각). 타일 = 틴트 박스(radius 26·accent-tint) + 가는 선 아이콘(화면 선두께 1.6px) + 이름 + 기록. **알약(999px) 금지** — 꼬리표·라벨은 radius 4, 진행 막대는 radius 3. HUD 는 테두리 상자가 아니라 구분선 한 줄.
6. **이모지 금지**(2026-08-25 오너 "이모지를 사용한 것만 해도 벌써 비슷한 느낌"). 아이콘·게임 그래픽은 전부 `games.html <defs>` 의 자체 심볼이다 — 게임 아이콘(`gi-*`, 가는 선 + currentColor)·도형 세트(`gs-*`, 면 채움 — 2-back 전용)·가위바위보 손(`gh-*` 3종, 가는 선 — 2026-08-26 신설, 구 `gs-paper` 종이 아이콘 폐기). 굵기는 심볼이 아니라 바깥 svg CSS 에서 준다(tools.html 의 use 그림자 트리 규칙). JS 는 `sym(id)` 로만 그린다.

## 파일 · 구조

- `games.html` — 허브(카드 7장) + 스테이지(소개 → 플레이 → 결과)가 한 파일. head 는 표준 장착(og 3종 동일 제목·nav.js·inapp.js·scroll-keep.js(defer 없음)·pageshow reload).
- `games.js?v=1` — 엔진(타이머·점수·화면 전환·기록) + 게임 7종 정의(`GAMES` 배열). **게임 추가는 이 배열에만** — 허브 카드·소개 화면은 배열에서 그린다. 파일을 고치면 `?v=` 도 같이 올린다.
- Supabase 를 싣지 않는다(비회원 공개·서버 판정 없음). nav.js 는 supabase 없이도 돈다(nav.js 머리 주석).
- 진입: tools.html 격자 7번 타일 + nav `TOOLS_SUB` 7번 항목. `SECTION_OF` 에 'games.html': 'tools' 등록됨(빼면 현재 위치 표시가 사라진다).
- 게임 화면 히스토리: 게임을 열 때 `pushState(#게임id)` — 폰 뒤로가기가 페이지 이탈이 아니라 목록 복귀가 된다. `#rps` 처럼 해시 딥링크도 열린다(이때는 상태를 push 하지 않는다 — 주석 참조).

## 연습/실전 두 모드 — 옵션 UI 금지

역검 사이트는 슬라이더(문항 수·도형당 시간)와 세트 선택을 나열하는데, **우리는 일부러 버튼 두세 개로 줄였다**(2026-08-25 오너 "이것보다 더 쉽게 느껴지도록"). 게임 정의의 `modes` 배열(첫 번째가 기본·진하게, 나머지 alt) 이 전부다 — **문항 수·시간 슬라이더를 다시 만들지 말 것.** 조절값은 모드에 고정값으로 박는다.

2026-08-26 오너가 N-back 캡처 3장을 주며 "그대로 베끼면 안되고 업그레이드를 시키라고" — 게임 정의의 **`opts` 필드**(key·label·def·items)를 엔진이 시작 버튼 위에 칩으로 그리고, 게임은 `api.opt(key)` 로 읽는다. 슬라이더·문항 수 조절은 여전히 두지 않는다(칩 한두 줄이 상한). 현재 opts 를 쓰는 게임: **2-back**(도형 세트 랜덤+5종 · 도형당 시간 3/4/6초), **개수 비교**(노출 시간 1/1.5/2초), **약속**(제시 속도 1/1.5/2초), **도형 회전**(글자 랜덤+7종 · 변형 미리보기 끔/켬). **속도류 옵션은 전부 연습에만 적용 — 실전 모드는 실전 수치 고정**(옵션이 실전 기록에 새면 기록 비교가 무의미해진다).

같은 날 오너 "기능이 한참 딸리는 느낌"으로 **세 가지를 보강했다**(슬라이더 금지는 유지).

- **결과 상세 피드백** — 정답률(맞힘/시도)·최고 연속·세그먼트별 성적(관점/라운드/글자·무늬별). 전부 엔진 `mark(ok, gain, seg)` 한 함수가 적는다 — **게임의 판정 지점은 반드시 mark 를 부른다**(addScore 는 폐지). 미응답·시간 초과도 mark(false)로 시도에 넣는다(안 넣으면 정답률이 거짓말).
- **HUD 연속 카운트** — mark 가 갱신, 틀리면 0.
- **부분 연습 칩(`parts` 배열)** — 약한 라운드만 반복(가위바위보 R1/R2/R3 · 숫자 1/2라운드 · 약속 4라운드). 도형 회전·2-back 은 modes 가 이미 그 역할.

## 구현 메모(함정)

- **점수 기록은 localStorage `monc_games_v1`** — 기기별 최고점·판수뿐, 개인정보 아님. scroll-keep 의 'sessionStorage 고정' 규칙은 위치 기록 얘기라 여기 적용 안 된다.
- **bfcache reload 표준 장착.** 게임 타이머가 `Date.now()` 기준이라 되살아난 화면은 이미 끝난 판이다 — reload 가 맞다. `scroll-keep.js` 는 defer 없이, 페이지 reload 처리보다 앞(CLAUDE.md).
- 연타 UI 라 `button { touch-action: manipulation }` + 보드 `user-select:none` — 빼면 더블탭 줌·텍스트 선택으로 화면이 튄다.
- rotate: 판정은 변형 행렬(css matrix) 비교 — **비대칭 글자(F G J L P R Q)·비대칭 무늬만 쓴다**(대칭이면 화면은 같은데 행렬이 달라 오답 처리된다 — 무늬는 생성 시 8변형 검사로 거른다). 버튼이 모양을 바꾸지 않는 것이 과제의 핵심 — 미리보기를 넣지 말 것.
- path: 퍼즐 생성은 '무작위 울타리 배치 → 시뮬레이션으로 출구 확정' 방식 — 안 쓰인 울타리가 있으면 다시 뽑는다(정답 울타리 수가 거짓말이 된다). 캡처의 '누른 위치로 / \\ 결정'은 터치에서 정밀도가 안 나와 **탭 순환**으로 바꿨다(의도한 차이).
- yaksok: 공통 라운드는 교집합이 정확히 1개인지 검증 후 출제. 버스 라운드 후보는 답 하나 빼고 전부 '누군가 탄 번호'에서만 뽑는다(안 그러면 답이 여럿이 된다).

## 게임감(주스) — 2026-08-25 오너 "성의 없고 대충 만든 느낌" 대응

규칙·기능이 실물과 같아도 **화면이 안 움직이면 대충으로 읽힌다**는 지적으로 연출을 전면 추가했다.
원칙 셋: ① 움직임은 **transform·opacity 만**(레이아웃 불변 — 넘침·겹침 재검증 불필요)
② 공통 연출은 **한 곳**(판정 배지=`flash()` · 등장=`dealIn()` · 카운트업=`countUp()`)
③ `prefers-reduced-motion: reduce` 면 전부 끈다(CSS 미디어 블록 한 곳).

- **판정 배지**: 모든 게임의 맞음/틀림에 체크·엑스 원형 배지가 보드 위로 팝(`flash()` 한 곳 — 게임별 코드 수정 없음). HUD 점수·연속은 오를 때 튄다(`bump`).
- **길 만들기**: 제출하면 **차량이 실제로 격자를 달린다**(`animateVehicles` — simulate 의 `trail` 을 따라 진입 표식→칸들→출구, 차례로 한 대씩, 틀린 차는 끝에서 흔들림). 판정·다음 문제는 재생이 끝난 뒤. 러너 색은 표식과 같은 `.col-*`(선택자에 `.gm-runner` 포함 — `.mk` 전용으로 되돌리면 먹색이 된다).
- **도형 회전**: 제출하면 '전' 도형이 **입력한 순서대로 실제로 돈다**(0.29s/단계) — 맞았으면 '후'와 겹치는 걸 눈으로 확인. 판정은 재생 후(`judge` 는 `!locked` 이면 스킵 — 실전 단계 전환과의 경합 가드).
- **가위바위보**: 라운드마다 **3·2·1 카운트다운**(카드 위 오버레이 — 레이아웃 안 밀림), 새 문제 카드 팝.
- **2-back**: 도형마다 **고정 색**(색=도형 1:1 이라 난이도 불변 — 길 만들기 기능색 3종+네이비 재사용, 새 브랜드색 아님) + 등장 팝.
- **개수 비교**: 가려진 판에 **'?' 커버**(빈 판은 고장처럼 보인다).
- **숫자 누르기·약속·경로**: 새 배열·암기 항목·후보가 순서대로 깔린다(`dealIn` — 약속 암기는 '순서 기억' 규칙을 화면이 거든다). 불 들어온 칸은 숨쉬는 펄스.
- **결과**: 점수 **카운트업** + 정답률·라운드별 성적 **막대**(`.r-bar`, 다음 프레임에 폭 부여) + 신기록 팝.
- 전 항목 Playwright 실플레이 검증(2026-08-25 — 러너·재생·카운트다운·배지·딜인·커버·카운트업 각각 존재/동작 확인, 콘솔 에러 0·넘침 0).

## 실전 반영 보강 — 2026-08-26 오너 "역량검사를 좀 잘 반영해서 해봐" 대응

규칙·수치는 캡처대로였지만 실전과 어긋나 보이던 두 자리를 고쳤다.

- **가위바위보는 손 모양으로**: 바위=동그라미(`gs-circle`)·보=종이 문서(`gs-paper`)로 그리던 것을 자체 드로잉 손 3종 `gh-rock`·`gh-scis`·`gh-palm` 으로 교체(실전은 손을 보여준다). `gs-paper` 는 폐기. 지금 답할 쪽(? 카드)은 카드째 강조(`.gm-hand.pick` — 랜덤 라운드에서 관점을 놓치는 게 최대 실점 요인이라 실물처럼 화면이 크게 말한다).
- **소개 화면에 예시 도해**: 실전이 매 게임을 그림으로 먼저 가르치듯, 게임 정의의 **`demo` 필드**(HTML 문자열)를 소개 화면 규칙 목록 위에 그린다(`.gm-demo` — nback 도형 3장+같다 / rps 상대 가위→나 바위 / path 울타리 하나로 꺾이는 경로 svg / rotate F→45°×2→90° / yaksok 세 명의 공통 '목' / numbers 불 켜진 자판 / compare 점 9 대 7). **새 게임을 추가하면 demo 도 같이 만든다.** 도해는 그림이지 조작 요소가 아니다(44px 터치 규칙 대상 아님, aria-hidden — 같은 내용이 규칙 목록에 있다). 색·칩·틴트는 전부 사이트 기존 값.
- 검증: 375·320 두 폭 × 7종 소개 화면 넘침 0 · 콘솔 에러 0 · 손 3종과 도해 7종 스크린샷 눈검사(2026-08-26).

**2차(같은 날 오너 N-back 캡처 3장 — "베끼지 말고 업그레이드"):**

- **2-back 도형 세트 선택** — 랜덤(기본)+세트 5종 칩, 칩에 색 미리보기. 실전 모드에도 적용돼 **취약한 세트만 실전 속도로 반복**할 수 있다. 세트 4·5용 도형 6종(`gs-heart/moon/bolt/drop/arrow/bowtie`) 자체 드로잉 신설, 도형 색은 모듈 스코프 `NB_COLOR` 한 곳(칩 미리보기 `symC()`와 게임이 공유).
- **도형당 시간 칩(연습)** — 3초(실전 속도)/4초(기본)/6초(느긋). **실전 모드는 3초 고정** — 시간 칩이 실전에 새지 않는다.
- **기억 단계 점선 카드** — 아직 답하지 않는 도형은 `.gm-nb-stage.lead .fr` 점선 프레임으로 구분(투명 테두리 상시라 전환 시 레이아웃 불변).
- **문항 진행 막대**(`.gm-prog`) — 제한시간 막대(`gm-qtimer`)와 별개.
- **PC 키보드 응답** — 실전이 PC 응시라 `pointer:fine` 환경에선 ←(2번째 전)/→(3번째 전)/Space(다름) 를 받고 버튼에 `<kbd>` 힌트를 그린다. 리스너는 `onCleanup` 에서 해제 — 빼먹으면 다른 게임에서도 키가 산다.
- 캡처의 **문항 수 슬라이더·'응답 후 진행' 토글은 일부러 안 가져왔다** — 모드 버튼(연습=맞히면 바로 다음/실전=시간 다 채움)이 이미 그 역할이다.
- 검증: 칩 6+3 렌더·세트 4 선택 시 세트 4 도형 출제·점선 카드·진행 막대·ArrowLeft 응답 판정 전부 Playwright 실측, 375·320 넘침 0·에러 0(2026-08-26).

**3차(같은 날 오너 "나머지도 이런 식으로 + UI 너무 허접, AI 가 후려놓은 티") — 전 게임 확장 + 게임판 디자인 재정비:**

디자인 진단: 흰 배경 위 흰 카드 위 흰 버튼이라 깊이가 없고, 버튼이 폼 컨트롤처럼 평평했다. 세 가지로 고쳤다 — 전부 기존 토큰 값이며 새 색 없음.

- **깊이 3층**: 게임판(`.gm-board`)은 옅은 필드(`--bg2`, radius 20) / 그 위 조각(도형 카드·손 카드·전후 카드·단어 판·격자 칸·암기 항목)은 **흰색 + 옅은 그림자**(`0 1px 2px rgba(23,42,71,.08)`) / 조작 버튼은 **키캡**. 이 층 구조를 깨는 흰-위-흰 회귀 금지.
- **키캡 감촉**: 게임 버튼류(`.gm-big`·판정·후보·변형·도구·숫자 칸·단어 판·부분 칩·옵션 칩·alt 시작 버튼)는 `box-shadow: 0 2px 0 rgba(23,42,71,.20)` 두께 + `:active` 에서 2px 내려앉음. 구 `scale(.95)` 단일 규칙을 대체했다. 숫자 누르기의 누른 칸(`.done`)은 그림자 없음(눌려 들어간 상태).
- **단계 칩**(`.gm-q .ph`): 라운드·모드 라벨은 본문 텍스트가 아니라 틴트 라벨(radius 4 — 알약 금지 유지). `:empty` 면 숨김.
- 게임별 확장(2-back 방식 그대로): **가위바위보** 키보드 1·2·3 + 버튼 kbd 힌트 + 연습에선 ? 카드에 방금 낸 손 공개(`choose()` — 340ms) / **개수 비교** 노출 시간 칩 + ←/→ 키(판 라벨에 화살표 힌트) + 진행 막대 / **숫자 누르기** 숫자 키 1~9 / **도형 회전** 글자 칩(약한 글자 반복)·변형 미리보기 칩(입문용 — 연습만, 켜면 재생 생략) + 진행 막대(연습) / **약속** 제시 속도 칩 + 진행 막대. 키 리스너는 각 게임 `onCleanup` 에서 해제.
- ⚠️ **미리보기 기본은 '끔·실전 방식'** — 버튼이 모양을 안 바꾸는 게 과제의 핵심이라는 원칙은 기본값으로 지키고, 켬은 입문용 명시 라벨로만 연다(실전 모드는 옵션 무시).
- 검증: 7종 소개 375·320 넘침 0, 보드 배경 bg2 실측, rps 키 1 응답·손 공개, compare 2초 노출·← 응답·진행, numbers 숫자 키 득점, rotate 글자 F 고정·미리보기 실회전·진행, yaksok 2초 제시·진행, nback 단계 칩 — 전부 Playwright 실플레이, 에러 0(2026-08-26).
