# 역량검사 게임 연습(games.html) — 상세 기록

> 2026-08-24 신설. 매 작업 공통 규칙은 CLAUDE.md 에 있고, 이 문서는 이 기능을 고칠 때 읽는다.

## 무엇인가 · 왜 만들었나

항공사 채용 전형에 AI역량검사(게임형)가 퍼지고 있어, 그 **게임 유형을 미리 손에 익히는 무료 연습장**이다.

- 2026-08-24 조사에서 확인한 사실: 제주항공은 자인원 역검 전용 응시 도메인(`jejuair.acca.ai`)이 실존, 파라타항공(구 플라이강원)도 동일(`parataair.acca.ai`). 티웨이(2026-10 트리니티항공으로 사명 변경 예정)는 2026-07 채용 전형에 '서류·역량검사·영상면접' 명시, 에어부산은 2025-07 채용부터 AI역량검사 신규 도입 보도, 진에어는 전형에 AI역량검사(1차 면접 뒤) 포함. **티웨이·에어부산·진에어의 검사 업체는 미확정** — 수강생 응시 안내 링크가 `*.acca.ai` 인지로 확정한다.
- **승무원 전형은 7종만 본다(2026-08-25 오너 확정)** — "승무원은 7개만 하거든. 고양이 술래잡기랑 마법약 만들기는 안 한다. 도형 순서 기억은 2-back 이랑 중복." 그래서 **고양이 술래잡기·마법약 만들기·도형 순서 기억은 만들었다가 제거했다 — 다시 넣지 말 것**(코드 이력은 git — 커밋 121b405 이전).
- 오너 확정: **무료, 결제·크레딧 없음.** 순수 클라이언트 게임이라 제공 원가가 0이다(서버·AI 호출 없음) — 유료화하려면 오너 결정부터.

## 지켜야 하는 선(법적 — 완화 금지)

1. **전부 자체 제작이다.** 잡다(자인원)의 화면·그래픽·캐릭터·문구·사운드를 가져오지 않는다(저작권). 게임 '유형'(도형 회전·순서 기억 같은 표준 인지과제)은 아이디어라 자유지만, **검사 전체 구성을 통째로 똑같이 재현하는 것도 피한다**(2019 대법원 팜히어로사가 판례 — 규칙 조합의 복제는 침해가 될 수 있다).
2. **"잡다"·"역검"을 서비스 이름처럼 쓰지 않는다.** 화면 이름은 '역량검사 게임 연습'. 개발사 언급은 고지문의 "자인원·잡다와 무관" 한 곳뿐 — 설명적 사용만.
3. **페이지 하단 고지(`.gm-note`) 삭제 금지**: 자체 도구·개발사와 무관·실제 검사와 다를 수 있음·실전은 PC 응시. 이 네 가지가 오인(공식 제휴로 보임)과 과신(이것만 하면 된다)을 막는다.
4. 실제 검사 화면 캡처를 레포·페이지에 싣지 않는다.
5. **이모지 금지**(2026-08-25 오너 "이모지를 사용한 것만 해도 벌써 비슷한 느낌"). 아이콘·게임 그래픽은 전부 `games.html <defs>` 의 자체 심볼이다 — 게임 아이콘(`gi-*`, 가는 선 + currentColor)과 도형 세트(`gs-*`, 면 채움 — 2-back 도형 세트·가위바위보가 공유). 굵기는 심볼이 아니라 바깥 svg CSS 에서 준다(tools.html 의 use 그림자 트리 규칙). JS 는 `sym(id)` 로만 그린다.

## 파일 · 구조

- `games.html` — 허브(카드 7장) + 스테이지(소개 → 플레이 → 결과)가 한 파일. head 는 표준 장착(og 3종 동일 제목·nav.js·inapp.js·scroll-keep.js(defer 없음)·pageshow reload).
- `games.js?v=1` — 엔진(타이머·점수·화면 전환·기록) + 게임 7종 정의(`GAMES` 배열). **게임 추가는 이 배열에만** — 허브 카드·소개 화면은 배열에서 그린다. 파일을 고치면 `?v=` 도 같이 올린다.
- Supabase 를 싣지 않는다(비회원 공개·서버 판정 없음). nav.js 는 supabase 없이도 돈다(nav.js 머리 주석).
- 진입: tools.html 격자 7번 타일 + nav `TOOLS_SUB` 7번 항목. `SECTION_OF` 에 'games.html': 'tools' 등록됨(빼면 현재 위치 표시가 사라진다).
- 게임 화면 히스토리: 게임을 열 때 `pushState(#게임id)` — 폰 뒤로가기가 페이지 이탈이 아니라 목록 복귀가 된다. `#rps` 처럼 해시 딥링크도 열린다(이때는 상태를 push 하지 않는다 — 주석 참조).

## 연습/실전 두 모드 — 옵션 UI 금지

역검 사이트는 슬라이더(문항 수·도형당 시간)와 세트 선택을 나열하는데, **우리는 일부러 버튼 두세 개로 줄였다**(2026-08-25 오너 "이것보다 더 쉽게 느껴지도록"). 게임 정의의 `modes` 배열(첫 번째가 기본·진하게, 나머지 alt) 이 전부다 — **문항 수·시간 슬라이더를 다시 만들지 말 것.** 조절값은 모드에 고정값으로 박는다.

같은 날 오너 "기능이 한참 딸리는 느낌"으로 **세 가지를 보강했다**(슬라이더 금지는 유지).

- **결과 상세 피드백** — 정답률(맞힘/시도)·최고 연속·세그먼트별 성적(관점/라운드/글자·무늬별). 전부 엔진 `mark(ok, gain, seg)` 한 함수가 적는다 — **게임의 판정 지점은 반드시 mark 를 부른다**(addScore 는 폐지). 미응답·시간 초과도 mark(false)로 시도에 넣는다(안 넣으면 정답률이 거짓말).
- **HUD 연속 카운트** — mark 가 갱신, 틀리면 0.
- **부분 연습 칩(`parts` 배열)** — 약한 라운드만 반복(가위바위보 R1/R2/R3 · 숫자 1/2라운드 · 약속 4라운드). 도형 회전·2-back 은 modes 가 이미 그 역할.

## 버그 제보 창구 — 자체 저장(game_reports)

처음엔 카카오톡 문의로 받으려 했으나 **오너 기각(2026-08-25 "카톡은 상담 문의에 관련된 내용이라 섞이면 안돼")** — 홈페이지에 내용이 남는 자체 폼으로 교체했다.

- 자리: `games.html` 하단 '게임 오류 제보' 접이 폼(허브·게임 화면 어디서든 접근) + 결과 화면 '오류 제보 남기기' 버튼(그 게임이 미리 선택된다).
- 저장: `game_reports` 테이블(마이그레이션 `20260825150000`). **anon INSERT 허용·SELECT 는 is_admin() 만.** 이 때문에 games.html 에 supabase CDN + supabase-config.js 를 탑재했다(게임 자체는 여전히 서버 무관).
- **연락처를 일부러 안 받는다** — 본문·게임·모드·UA 뿐(로그인 상태면 member_id 자동). 답변형 문의는 상담 창구 몫이고 이건 버그 기록함. 연락처 칸을 추가하려면 개인정보 항목이 늘어나는 결정이라 오너 확인부터.
- degrade: 테이블 미생성(PGRST205)·전송 실패 시 "준비 중/실패" 안내만 — 게임에 영향 없음. 재전송 남용은 60초 쿨다운(localStorage).
- 확인 창구: 당분간 Supabase Table Editor. admin '게임 제보' 목록은 탭 배치(운영 그룹) 정한 뒤 추가.

## 구현 메모(함정)

- **점수 기록은 localStorage `monc_games_v1`** — 기기별 최고점·판수뿐, 개인정보 아님. scroll-keep 의 'sessionStorage 고정' 규칙은 위치 기록 얘기라 여기 적용 안 된다.
- **bfcache reload 표준 장착.** 게임 타이머가 `Date.now()` 기준이라 되살아난 화면은 이미 끝난 판이다 — reload 가 맞다. `scroll-keep.js` 는 defer 없이, 페이지 reload 처리보다 앞(CLAUDE.md).
- 연타 UI 라 `button { touch-action: manipulation }` + 보드 `user-select:none` — 빼면 더블탭 줌·텍스트 선택으로 화면이 튄다.
- rotate: 판정은 변형 행렬(css matrix) 비교 — **비대칭 글자(F G J L P R Q)·비대칭 무늬만 쓴다**(대칭이면 화면은 같은데 행렬이 달라 오답 처리된다 — 무늬는 생성 시 8변형 검사로 거른다). 버튼이 모양을 바꾸지 않는 것이 과제의 핵심 — 미리보기를 넣지 말 것.
- path: 퍼즐 생성은 '무작위 울타리 배치 → 시뮬레이션으로 출구 확정' 방식 — 안 쓰인 울타리가 있으면 다시 뽑는다(정답 울타리 수가 거짓말이 된다). 캡처의 '누른 위치로 / \\ 결정'은 터치에서 정밀도가 안 나와 **탭 순환**으로 바꿨다(의도한 차이).
- yaksok: 공통 라운드는 교집합이 정확히 1개인지 검증 후 출제. 버스 라운드 후보는 답 하나 빼고 전부 '누군가 탄 번호'에서만 뽑는다(안 그러면 답이 여럿이 된다).
