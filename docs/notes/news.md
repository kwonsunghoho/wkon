## ⚠️ 2026-09-07 부활(v2) — 이 절이 현행 규칙이다

오너 지시 원문: *"뉴스 스크랩 기능을 다시 사용하려고하는데. 승준도구"*, 이어 *"저번에 보니까 다른 학원의 뉴스도 스크랩해왔더라고"*, *"스크랩해온 뉴스를 이동하지않고 우리 홈페이지에서 바로 볼 수는 없나? 솔직히 링크만 긁어오는거 자체가 뭔 의미가있어. 우리 홈페이지 폰트나 규칙그대로 볼 수 있어야 좋은거 아니야?"*

설계서는 `docs/superpowers/specs/2026-09-07-news-scrap-v2-design.md`, 구현 계획은 `docs/superpowers/plans/2026-09-07-news-scrap-v2.md`. **아래 폐지 절과 그 아래 v1 상세는 역사 기록이다** — 값이 다르면 이 절이 맞다.

- **노출은 승준 도구 안에서만**(오너 확정 A안): 도구 허브 카드(첫 칸)·nav '승준 도구'·뉴스 페이지·마이페이지 접이. **홈은 건드리지 않았다**(칩·문구·클로징 링크 전부 폐지 후 상태 그대로). **승준 코스의 뉴스 단계도 되살리지 않았다.**
- **수집 출처 = 네이버 뉴스 검색 API**(`scripts/fetch-news.mjs` 의 `fetchNaver`). ⚠️ **구글뉴스 RSS 로 되돌리지 말 것** — ① 피드 저작권 문구가 개인·비상업 용도만 허용 ② 링크가 암호화 주소라 원문 URL 을 못 꺼내고, 그러면 요약을 가져올 수 없다(2026-09-07 실측: plain fetch 가 580KB JS 페이지를 주고 원문 도메인 문자열 0건). 블로그 판정도 `source` 문자열이 아니라 **URL 호스트**(`badSource`)로 바뀌었다 — 네이버 API 가 언론사명을 주지 않는다.
- **요약(`summary`)은 언론사가 공유용으로 공개한 `og:description`** 한두 문장을 수집 시 1회 읽어 300자까지 저장한 것이다(`fetchOg` — 신규 행에만, 동시 4개·8초 타임아웃·512KB 상한·자기소개 User-Agent). 폴백은 네이버 발췌문 → 없음. ⚠️ **기사 본문·사진을 저장하거나 표시하지 말 것**(저작권). 읽기 창에는 언론사명과 '원문 읽기' 링크를 항상 함께 둔다. AI 요약도 쓰지 않는다(비용·오요약·언론사 반발 — 오너에게 설명 후 기각).
- **읽기 창**(`#nwReader`): 카드 본문이 `<a target="_blank">` 가 아니라 `<button class="nw-open">` 이고, 누르면 바텀시트가 올라온다(칩·제목·언론사·날짜·요약·[스크랩]·[원문 읽기 · 언론사명 ↗]·[닫기], 스크랩한 기사면 메모·태그 편집기). ⚠️ **링크로 되돌리지 말 것** — 이 기능의 요구 자체다. 폰 뒤로가기는 `pushState`+`popstate` 로 창만 닫는다. `news.html?a=<기사 id>` 는 그 기사를 바로 여는 진입 규약(마이페이지 접이가 쓴다 — 없는 id 면 '지워진 기사예요' 토스트).
  - ⚠️ **메모·태그 편집기는 `extrasHtml`/`bindExtras` 공용 함수 한 벌**이다 — 내 스크랩 탭과 읽기 창이 같은 코드를 쓴다. 복사하면 한쪽만 고쳐져 동작이 갈린다.
  - ⚠️ **`.nw-reader-actions .nw-bm::after { content: none; }` 를 지우지 말 것**: 기저 `.nw-bm::after{inset:-4px}`(터치 44px 확장)가 `position:static` 인 읽기 창 버튼에서는 컨테이닝 블록이 fixed 시트가 돼 **창 전체를 투명하게 덮는다**. 닫기·원문 읽기가 눌리지 않고 요약을 짚기만 해도 스크랩이 토글됐다(2026-09-07 리뷰에서 재현).
  - ⚠️ **`wasDrag` 의 `e.detail === 0` 예외**를 지우지 말 것: 키보드 Enter/Space 가 만든 click 은 좌표가 0이라, 포인터를 한 번 쓴 뒤에는 카드가 키보드로 안 열렸다. **Tab 포커스 트랩**과 **스크림 상호 존중**(`hideReader`/`closeSheet` 가 상대 창이 열려 있으면 `open` 을 안 지운다)도 같은 리뷰의 산물이다.
- **학원·학과 홍보 제외**(`ACADEMY`): 학원·아카데미·합격자/합격생 배출·수강생·항공서비스/운항/관광 학과·취업연계. ⚠️ **'양성'·'교육'·'대학' 단독을 넣지 말 것** — 실측 오탐("에어부산…항공산업 인재 양성", "대한항공, 아시아나항공과 교육기부 봉사"). `AVIATION` 게이트보다 앞에 둔다(학원 기사에도 '승무원'·'항공'이 있다). ⚠️ 규칙의 `항공(서비스|운항|관광)\s*(학과|학부|과)\b` 갈래는 JS `\b` 가 한글 뒤에서 성립하지 않아 **사실상 죽은 조건**이다(미탐 방향 — 오탐 0 기준은 통과). 대안 `(?![가-힣])` 는 "국토부, 항공운항과 안전 점검"이 새로 걸려 기각했다. 손대려면 공백까지 막는 별도 설계가 필요하고, 실데이터 dry-run 으로 확인할 것.
- **보관**: 기사 90일, 스크랩된 기사는 영구(v1 규칙 그대로).
- **검증 방법**: `node scripts/fetch-news.mjs --dry-run`(네이버 키 필요) 또는 Actions 수동 실행 `mode=dry-run`. `--summary-test <url>` 로 매체별 요약 추출 확인, `--pages N` 으로 검색어당 페이지 수(첫 씨앗 채우기는 5). ⚠️ 규칙을 고쳤으면 **'제외' 목록을 눈으로 확인**할 것 — 이 필터는 못 걸러서가 아니라 정상 기사를 걷어내서 망한다.

## ⚠️⚠️ 뉴스 기능 전체 폐지 (2026-08-28)
