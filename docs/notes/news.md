## news.html 게시판(구 CLAUDE.md Pages 항목)

- `news.html` — **항공 뉴스 게시판(2026-07-22 배포).** 2탭(전체 뉴스 / 내 스크랩). 필터 = 제목 검색창 + **[항공사]·[주제] 픽커 버튼 2개 → 바텀시트 선택**(2026-07-23 오너 지시 "지저분하게 나열하지 말고 눌러서 선택" — 구 칩 나열 폐기). 버튼 라벨이 선택값으로 바뀌며 `.set` 틴트 — 현재 필터 상태가 항상 보인다. 옵션은 최근 1000건에 실존하는 값만 렌더. 기사 시각은 상대시간("3시간 전")이 아니라 **게시 날짜 YYYY.MM.DD**(`fmtDate`, 2026-07-23 오너 "시간은 의미 없다"). ⚠️ 칩 나열(가로 스크롤 줄)로 되돌리지 말 것 — sticky 필터바가 375px 화면의 70%를 차지하던 실측 문제로 회귀한다. `.nw-filter-row`/`.nw-chip` CSS는 내 스크랩 탭 '내 태그' 줄이 아직 써서 남겨둔 것(삭제 금지). 스크랩 버튼은 **창문 심볼 + 글자 라벨 알약**(인라인 `#moncWin`, 전=`grayscale(1)`+'스크랩' / 후=원색+'저장됨'+코랄 틴트). 리본 북마크로 되돌리지 말 것이며 원본 SVG는 로고 교체(a5f1b85)로 삭제됐으므로 **인라인 심볼이 정본**이다. ⚠️ **라벨을 빼고 아이콘만 두지 말 것**(2026-07-22 오너 피드백 "저게 스크랩인지 모르겠다") — 창문은 브랜드 심볼이지 '저장'의 관습 기호가 아니라 아이콘 단독으로는 무슨 버튼인지 안 읽힌다. 시각 높이 36px에 `::after{inset:-4px}`로 터치 44px를 만들고, `.nw-link`의 `padding-right:98px`가 알약(≈75px) 자리를 비운다 — **알약은 absolute라 제목이 자동으로 안 밀린다. 라벨 길이를 바꾸면 이 여백도 같이 볼 것.**

- ⚠️ **같은 소식 접기(2026-08-01 오너 확정)** — `news.html` 의 `appendRows()`·`FOLD_SIM`. **같은 날 + 같은 항공사 + 제목 낱말 유사도 0.15 이상**이면 뒤엣것을 대표 카드 안 `.nw-sublist` 로 접고 "같은 소식 N건 더 보기" 버튼을 단다. 수집기의 중복 묶기(0.5)로 못 잡는 도배가 대상이다 — 부여군-에어로케이 업무협약 8건은 서로 유사도가 0.06~0.29 라 제목만으로는 안전하게 지울 수 없었다.
  - **임계값이 수집기(0.5)보다 훨씬 낮은 건 실패 비용이 달라서다** — 수집기는 지우지만 여기는 접을 뿐이라 잘못 묶여도 펼치면 그대로 보인다. **지우는 쪽으로 옮기지 말 것.**
  - **⚠️ 날짜·항공사만으로 묶지 말 것**(첫 구현이 그랬다): 같은 날 대한항공 기사 26건이 통째로 한 묶음이 됐고 '기내식 자회사 지분 인수 연기'·'MRO 아웃소싱 확대' 같은 **면접 재료가 '출국 팁' 도배 밑으로 숨었다.** 유사도 조건을 넣으니 4건·3건짜리 묶음 여럿으로 갈렸다.
  - **⚠️ 주제(topic)는 조건에 넣지 말 것** — 같은 사건인데 언론사마다 service/policy 로 갈려 들어온다(에어서울 결항 실측). **항공사 미분류(null)는 아예 묶지 않는다**(업계 일반 기사라 같은 날이어도 다른 사건).
  - 실측(100건 로드): 최상위 63 + 접힘 37, 묶음 12개. 375px 에서 버튼 45.8px·활자 13px·하위 카드 제목 14px·가로 넘침 없음.

### 항공 뉴스 수집 파이프라인 (`scripts/fetch-news.mjs` + `.github/workflows/news.yml`)
**이 레포에서 유일하게 서버처럼 도는 것.** 구글뉴스 RSS 12쿼리(항공사 10개사 + '항공사 채용'·'국내 항공업계') → 분류 → `news_articles` upsert. GitHub Actions가 **3시간마다** 실행하며 `SUPABASE_SERVICE_ROLE_KEY`는 **GitHub Secrets**에 있다(오너 등록 완료). 테이블은 migration `20260721120000_news_board.sql`(owner 실행 완료) — 읽기 공개, 쓰기는 service role만.
- **로컬 검증**: `node scripts/fetch-news.mjs --dry-run` — DB 없이 파싱·분류·제외 결과와 미분류 비율을 찍는다. **규칙을 고치면 반드시 dry-run으로 실데이터에 대고 확인할 것**(정규식 한 줄이 수백 건을 좌우한다).
- ⚠️ **분류는 저장 시점에 고정된다.** `AIRLINES`·`TOPICS`를 고쳐도 과거 기사엔 반영되지 않아 재분류 스텝(7)이 매 실행 소급 적용한다 — 이 스텝을 지우면 키워드를 확대해도 **DB 통계가 변하지 않는다**(실제로 겪은 자리: 규칙상 36%인데 DB는 63%였다).
- ⚠️ **참사 보도 제외**(2026-07-22 오너 결정, 승무원 지망생이 보는 화면이라): `EXCLUDE` 정규식. **`RESCUE` 예외를 지우지 말 것** — "승무원 신속 대응으로 참사 막았다"는 참사 보도가 아니라 승무원 대응 미담이고 준비생에겐 최상급 면접 소재다(첫 시험에서 실제로 오탐된 자리).
- ⚠️⚠️ **취업 무관 보도 제외(2026-07-30 오너 지시 "취업이랑 아무런 연관이 없잖아")** — 뉴스판 최상단이 *"'와 7kg 빠졌다' 대한항공 방출 선수, 한국전력 이적을…"*(프로배구 점보스)였다. 항공사 **이름으로 검색하니 같은 이름의 스포츠단·주식 종목·협찬 기사가 함께 딸려 온다.** `dropReason()`이 사유별로 판정하고, **수집(스텝 2)과 기존 저장분 청소(스텝 6)가 같은 `isDropped()`를 쓴다.**
  - **⚠️ 세 갈래를 서로 다른 방법으로 막는다 — 하나로 묶지 말 것**: ① 스포츠(`SPORTS`)·시황(`STOCKS`)은 **있으면 버리는 낱말**(블랙리스트) ② 항공 무관 기업 기사는 낱말을 셀 수 없으니 **항공 낱말이 하나도 없으면 버린다**(`AVIATION` 화이트리스트 + `mentionsAirline`) ③ 블로그·카페는 제목이 아니라 **출처**(`BAD_SOURCE`)로 판단.
  - **⚠️ 경영·실적·합병·유가·화물은 절대 빼지 말 것** — 기업분석 면접 답변의 핵심 재료다. 거르는 건 '투자 판단용 시황'(목표주가·투자의견)뿐이다.
  - **⚠️⚠️ 이 필터는 못 걸러서가 아니라 정상 기사를 걷어내서 문제가 된다**(AI킬러 규칙과 같은 실패 모드). 첫 시험에서 실제로 확인한 오탐 4종 — 되돌리지 말 것: **`골프`**(→"에어서울, 항공·숙박·골프 묶은 원스톱 여행"이 제외된다. 골프단 협찬만 좁게) · **`제주항공우`의 `(?![가-힣])`**(→"제주항공**우주**박물관"이 우선주로 잘린다) · **`mentionsAirline`**(→`진에어`·`에어프레미아`·`티웨이`처럼 이름에 '항공'이 없는 6개사 기사가 전부 잘린다) · **`한진칼`·`한진그룹`**(→대한항공 지주사 경영권 분쟁은 면접 단골인데 제목에 '항공'이 없다). 단독 금지 낱말: `방출`("탄소 방출") · `선수`("선수금") · `감독`("금융감독원") · `에어`("에어컨").
  - **⚠️ `이스타` 별칭**은 제목의 줄인 표기("이스타-관광공사…") 때문에 필요하다 — 빼면 그 기사가 '항공무관'으로 잘린다. 슬러그는 그대로라 news.html·mypage 라벨 계약에 영향 없다.
  - **검증 실측(2026-07-30, 실데이터 1,126건)**: 제외 15건(스포츠 2·항공무관 7·시황 1·블로그 1·참사 4), 오탐 0. 규칙 수정 전 첫 시험은 219건을 걷어냈고 그중 상당수가 오탐이었다 — **숫자가 크면 잘 걸러진 게 아니라 잘못 걸러진 것이다.**

- ⚠️⚠️ **여행상품·판촉 보도 제외(2026-08-01 오너 지시 "여행사 상품기사를 왜 스크랩하는거야")** — `TRAVEL_AD`. 여행사 패키지 출시(한진트래블 전세기 상품), 항공권 특가·할인 프로모션(에어서울 '파이널 앵콜', 에어부산 FLY&SALE), 소비자용 '출국 꿀팁' 보도자료가 대상이다. **항공사가 파는 상품이라도 판촉 기사는 뺀다** — 2026-07-30 당시 '골프' 항목에서 "항공사가 파는 여행 상품은 남긴다"고 적었던 판단은 이 지시로 뒤집혔다(단 `SPORTS` 에 '골프'를 넣지 말라는 규칙 자체는 그대로 유효 — 이유가 다르다).
  - **⚠️ `AD_KEEP` 예외를 지우지 말 것**: 판촉 낱말이 든 업계 분석 기사를 되살린다. 실측 오탐 — "휴가철 프로모션 대거 쏟아낸 LCC…'출혈경쟁' 우려 커진다"(LCC 수익성 분석, 면접 재료).
  - **`MUSEUM`(제주항공우주박물관)** — JDC 산하 과학관인데 이름이 '제주항공'과 겹쳐 **15건이 전부 `airline='jejuair'` 로 잘못 분류**돼 있었다(항공사 필터에서 제주항공을 고르면 천문캠프·입장료 할인 기사가 나왔다). ⚠️ '항공우주산업'(KAI)은 걸리지 않는다 — 넓히지 말 것.
  - 같이 고친 기존 규칙 오탐 2건: **`SPORTS` 의 `(?<!지)배구`** — 없으면 '지배**구조**'가 걸려 "계열사 지배구조 정비·마일리지 통합…대한항공의 숙제"가 스포츠로 잘린다. **`AVIATION` 의 `결항|회항|탑승|수하물`** — 제목에 항공사도 '항공'도 없이 사건만 적는 기사가 있다("승객 200여 명 탑승한 채 3시간 기다리다 결항").
  - **검증 실측(2026-08-01, 수집 1,138건)**: 제외 139건(여행상품 119·스포츠 3·항공무관 9·참사 7·박물관 1), 제외 목록 눈 검사 오탐 0. DB 저장분 1,000건 기준으로는 84건 제외.

  - 수집 시점(스텝 2·3)과 기존 저장분 정리(스텝 6-2)가 같은 `similar()` 를 쓴다. 정리는 **먼저 실린 원 보도 1건만 남기고**, **스크랩된 기사는 무조건 남긴다**(cascade 로 회원 재료함이 날아간다).
