# 강사 채용 공고 이미지

- 공개 이미지: `images/recruitment/monc-instructor.png` (1720 × 6135px, 표시 폭 860px).
- 공개 주소: `https://monc.ai.kr/images/recruitment/monc-instructor.png`.
- 사람인·잡코리아 상세 공고에 공통으로 삽입하는 승인된 이미지다. 학생 본연의 장점과 가능성을 이끌어내는 교육관을 담는다.
- 이미지에는 채용 사이트명·접수기간·마감일을 넣지 않는다. 접수기간과 마감 설정은 각 채용 사이트에서 관리한다.
- 보수·업무량은 미정이며 강의 경력 무관이다. 자료 보호·외부 활동 제한 문구는 넣지 않는다.
- 홈페이지 인재 채용 페이지는 `talent.html` + `talent.css`이며 홈 하단에서 연결한다. 2026-10-20 오너가 홈페이지 공개를 승인했다. 공고 이미지를 늘여 붙이지 않고 같은 내용을 반응형 텍스트와 도식으로 제공한다.
- 지원 버튼은 `talent-apply.html`의 비회원 자체 지원서로 연결한다. 외부 공고 주소는 사용하지 않는다.

- 원본 HTML을 Chrome PNG 렌더러로 2배 해상도 출력한다. JPEG를 변환하지 않으며 PNG 파일 시그니처와 실제 이미지 형식을 검증한다. 기존 JPG 주소는 이전 공고 호환을 위해 유지한다.

## 자체 지원서 (로컬 구현, 운영 미적용)

- 공개 화면: `talent-apply.html/css/js`, 비회원 API 연결: `talent-api.js`. 이름·연락처·이메일·경력·자기소개 네 문항과 미체크 필수 동의. 파일 첨부는 없고 필요 시 별도 요청한다. 분석 스크립트·회원 설정·로컬 영구 초안 저장을 싣지 않는다.
- 관리자: 운영 메뉴의 `talent-admin.html` + `talent-admin.js/css`. `MONC.requireConsent()`와 `is_admin()` 확인 후 조회. RLS도 관리자만 조회·상태 수정 허용. 지원자 답변은 textContent로만 표시하며 자동 평가하지 않는다.
- 서버: `talent-submit`, FN_VERSION `2026-10-20.1`. JWT 검증은 켜 둔다. 비회원은 기존 공개 anon JWT로 접수하며 개인정보 조회 API는 없다. 필수 동의와 길이·형식을 서버에서도 검사한다. 응답에는 접수번호만 포함한다.
- SQL: `20261017100155_talent_applications.sql`. anon 직접 읽기/쓰기 금지, 서비스 역할만 접수 RPC 실행. 원자적 제한: IP 해시당 시간당 5건, 연락처 해시당 하루 3건, 전체 하루 200건. 허니팟·32KB 본문 제한·UUID 재시도 중복 방지. 원본 IP는 저장하지 않는다.
- 보유: 접수 후 90일. pg_cron이 매시간 만료 자료를 삭제한다(만료 뒤 최대 1시간). 운영 전 cron 설치와 실제 작업 등록을 확인해야 한다.
- 미리보기: `__talent*-preview.html`은 운영 API를 싣지 않는 가상 제출·관리자 화면이며 배포 금지. 가상 데이터만 해당 탭의 sessionStorage에 저장한다.
- 운영 SQL과 Edge Function 배포, 실 DB 권한 검증은 아직 미실행. 화면 승인 후 기존 Supabase 콘솔 적용 절차로 진행한다. DB 미생성은 접수/관리자에서 실패 안내하고 성공으로 표시하지 않는다.

- 검증: Deno 타입 검사 및 접수 검증 4개 통과. 로컬 PostgreSQL(PGlite)에서 권한·중복/횟수 제한·만료 차단/파기 11개 통과. pg_cron 설치·스케줄 실행과 운영 권한은 미검증. 가상 화면에서 동의 미체크 차단, 제출 완료, 관리자 상태 저장/필터 확인.

- 이력(학력·졸업 여부, 주요 경력, 강의·코칭 경험, 활동 가능 일정)과 자기소개를 분리한다. 자기소개는 승인된 장점 발견·소통 조정·피드백 수용·책임 지속 네 문항, 각 500자 이내이며 최소 분량은 없다. 관리자도 기본 정보/이력/자기소개로 나눈다. 미배포 마이그레이션 원본에 반영했으며 운영 변경은 없다.

## 2026-10-20 홈페이지 공개 준비

- 오너 요청으로 페이지·홈 하단 링크·관리자 진입 링크를 배포한다. 실제 SQL/함수는 콘솔 적용 대기이며, anon 프로브 HTTP 404 확인.
- 실제 지원서 화면은 개인정보 입력 전에 서버 준비 상태를 확인한다. 함수 미배포/저장소 미생성/연결 실패 시 입력 폼을 열지 않고 접수 준비 중을 안내한다. 함수와 SQL 적용 후 준비 프로브가 통과하면 자동으로 입력 폼을 연다.
