타겟 3부류는 원인이 다르다(작은 목소리 = 호흡·공명, 목 아픔 = 과긴장·후두 상승, 탁성 = 성대 접촉). 부류별 처방·커리큘럼은 오너가 직접 짠다. 탁성 병리 스크리닝 문구는 넣지 않기로 했다(오너 결정).

### 운영 흐름

```
신청 → 카톡 채널로 녹음 접수 → 녹음 듣고 선정
  → 선정자에게 특강 페이지 결제 링크 발송 → 결제 시 확정
  → 첫 수업 전 진단 1장 발송 → 주 1회 수업 + 보신각 채널 매일 미션
  → 수료 후 스피치 안내
```

- 결제는 기존 특강 상세(`lecture.html?id=`)를 "선정자 결제 전용"으로 쓴다. 사이트 수정 없음.
- 녹음은 사이트 폼이 아니라 카톡 채널로 받는다.

### 아직 정하지 않은 것

- 기간(몇 주). 19만원이면 4주 4회(회당 47,500원)가 최소 비용 포지션에 맞다는 의견을 냈다.
- 장소.
- 강사 구성. 8명 개별 점검을 120분에 넣으려면 보조 연구원 1명 또는 정원 6명이 대안.
- 미선정 안내의 "느낀 점 한 줄" 유지 여부(인원 많으면 부담).
- 후기 활용 동의를 결제 전에 받을지, 첫 수업 때 서면으로 받을지(결제 전이 분쟁이 적다).
- 스피치 연결 상품이 기존에 있는지, 새로 여는지.

## 3. 인스타 표지·이미지 방향

레퍼런스는 AI 뉴스 계정(AI FREAKS)의 그리드. 카드마다 카테고리 라벨 + 흰 굵은 헤드라인 2줄 + 하단 로고가 고정이고, 이미지는 화면 캡처·3D 오브젝트·인물 사진·생성 이미지가 섞인다.

### 확정

- **비율 4:5, 1080×1350.** 카드뉴스 스킬 캔버스와 같다. 3:4(1080×1440)는 그리드 잘림이 없지만 캐러셀 안에서 비율이 섞이면 다른 장이 잘린다. 1:1은 세로 공간 손해.
- **활자 체계만 고정한다.** 라벨 · Pretendard Black 헤드라인 2줄 · 하단 단색 흰 로고. 이게 그리드를 한 브랜드로 묶는 장치다. 값은 카드뉴스 스킬(`assets/cardnews.css`) 그대로: 네이비 `#0F2E68`, 아이보리 `#F7EFEB`, 좌우 64px, 좌측 정렬.
- **이미지는 전면에 깔고 하단에 네이비 그라데이션 스크림.** 레퍼런스 구조 그대로.
- **한글은 이미지에 넣지 않는다.** 카피는 카드 툴에서 얹는다. 프롬프트마다 하단 45%를 비워 두는 지시를 넣는다.
- **표지 한 장만 사진 예외.** 카드뉴스 스킬의 사진 금지 규칙은 안쪽 장에 그대로 유지한다.
- **항공사 로고·CI 색·유니폼·실제 영상면접 화면 UI는 생성 이미지에 재현하지 않는다.** 항공사 이름은 헤드라인 글자로만 쓴다(특강 카드가 항공사명을 다루는 방식과 같다).
- **후킹 기준**: 헤드라인을 읽기 전에 "목소리 얘기구나, 나다"가 보여야 한다. 피드에서 멈추게 하는 건 얼굴과 긴장이지 틀이 아니다.

### 기각: 창문 로고를 이미지 틀로 쓰는 안(2026-09-17)

로고 O 비율의 큰 창문 안에 장면을 넣고 아래에 헤드라인을 두는 목업을 1080×1350으로 만들어 봤다(창틀은 네이비 바탕이라 아이보리로 반전, 창 안은 `hero-sky-sunset.webp`). 오너 판정 "쌩뚱맞다". 이유 두 가지.

1. 비행기 창은 뜻이 "기체 바깥"이라 창 안에는 하늘밖에 못 넣는다. 면접실·파형을 넣으면 논리가 깨진다. 결국 하늘 변주만 남고, 하늘은 "목소리가 작거나"와 관계가 없다.
2. 창문 틀은 브랜드 일관성 장치이지 후킹 장치가 아니다.

창문은 로고 O 안에 이미 있으니 그걸로 충분하다. 큰 창은 하늘이 주제인 게시물(합격 소식 등)에만 쓴다.

### 반복 시각 언어

캐릭터(마스코트)보다 오브젝트를 권했다. 캐릭터는 브랜드 결정이 커서 실패하면 되돌리기 어렵고, 오브젝트(창문·탑승권·스카프·명찰·마이크)는 게시물마다 바꿔도 톤이 유지된다. 리포트 게시물은 실제 리포트 페이지 캡처를 쓴다(비용 0, 우리 장점을 그대로 보여준다). 카테고리 라벨 서너 개(예: 채용 NEWS / 진단 TIP / 리포트 / 모집)는 오너 미정.

### 표지 이미지 후보(후킹 순)

1. **영상면접 녹화 화면 정면**(오너 제안, 2026-09-17) — 증상보다 상황이 세다. 승준생이 곧 찍을 화면이라 자기 투영이 된다. 영상면접은 마이크가 작은 목소리를 더 작게 만들고 탁성을 더 드러내니 보이스 반과 논리가 붙는다. 우리 자산도 있다: 잡페어 영상면접 상담 실사 `images/hero-expression.webp`, 실제 지원자 셀프 녹화 화면을 흐리게 깐 `images/door-challenge.webp`(둘 다 오너 소유).
2. **목에 손을 댄 지원자 + 면접 대기실 맥락** — 증상이 바로 읽힌다. 맥락 없이 찍으면 감기약 광고처럼 보인다.
3. **사라지는 "목소리" 타이포**(GPT Image 2) — 글자가 증상을 연기할 때만 후킹이 된다. 타이포는 뉴스·리포트 발표 카드에서 힘을 발휘한다.

헤드라인 후보: "영상면접, 목소리부터 걸린다" / "화면 속 내 목소리가 작다면" / "목소리가 작거나 / 말하면 목이 아프다면". 문구는 오너 미정.

## 5. 힉스필드 운용 메모(2026-09-15 실측)

- 계정 플랜 Plus. Claude Code에 MCP 커넥터로 연결됨(`claude mcp add --transport http --scope user higgsfield https://mcp.higgsfield.ai/mcp`, API 키 없이 계정 로그인).
- **무제한은 higgsfield.ai 웹에서만 적용된다.** MCP 경유 생성은 `unlim.available:false`로 크레딧 차감. 대량 생성은 웹에서, 이 세션(MCP)은 소량 편집·확인용.
- 웹에서도 크레딧이 찍히면 원인은 다섯 중 하나: Unlimited 토글 꺼짐(Credit Mode = 우선 큐) / 해상도·길이가 상한 위(영상 720p 상한, 4K·업스케일은 크레딧) / 그 모델의 무제한 창 종료(영상 모델은 7~33일 창) / Canvas·MCP·CLI 경로 / 부가 기능(업스케일·확장).
- 공식 문구상 Soul V2·Cinema는 "수천 회 무료 생성"이라 엄밀히는 큰 한도이지 무한이 아니다.
- 워크스페이스 `is_selected:false` 상태였다. MCP로 생성하기 전 선택이 필요할 수 있다(오너가 선택 지시 → 커넥터 끊김으로 미완).
