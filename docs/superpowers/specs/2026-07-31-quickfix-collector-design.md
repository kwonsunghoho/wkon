# 미니 다듬기(quickfix) — 표현 수집 창구 설계 (2026-07-31 확정)

> 운영 상세·회귀 금지 규칙은 `docs/notes/quickfix.md` 가 원장. 이 문서는 **왜 이렇게 정했는지**의 기록.

## 배경 — 오너 요청 원문 요지

*"답변프로그램·AI킬러·소재발굴에 사용자들의 경험과 데이터를 확보하고 싶다. 반복된 표현이나
AI 티 나는 어휘 데이터를 모집하고 싶다. 대놓고 모집하기보단 '하단이나 상단에 AI 느낌이 나는
구간을 넣어주시면 수정해드려요' 같은 기능을 넣는 거지. UI 가 중요하다 — 방해받지 않고
자연스럽게 녹여져야 한다."*

배경 문제(메모리 실측): AI킬러의 약점은 오탐이 아니라 **미탐** — coach 사전이 임시 시드뿐이라
"아무 말도 안 하는" 검사였다. 이 수집이 그 사전을 살찌우는 공급로다.

## 확정 사항 (오너 답변)

1. **사용 범위 = 로그인 회원만.** 도구 페이지가 이미 로그인 게이트라 자연 성립. 악용·비용 통제.
2. **결과 = 즉석 AI 고침, 무료.** Haiku 4.5(건당 몇 원 미만), 300자 이내, **하루 3회**(쪼개 넣어
   킬러 무료 우회 차단).
3. **B안 채택** — 서버가 `spotted [{표현, 종류, 이유}]` 를 구조화해 쌓고, admin 이 **표현별
   빈도 순위**로 집계(오너: *"수집된 특정 어휘나 표현 같은 걸 보기 쉽게. 공통적으로 싫어하는
   어휘·어조·문맥을 파악하고 싶다"*). 종류는 기존 사전 3종(상투어/구조/문맥)에 그대로 대응.
4. **고객의 소리(VoC) 위젯은 삭제** — 오너 지시("고객의소리는 일단 삭제해라"). 제안했던
   feedback.js 바텀시트+admin 탭 설계는 이 문서에만 남긴다(부활 시 별도 확정).

## 기각안

- **C안(새 UI 없이 기존 `ai_killer_checks` 채굴만)**: "우리가 판정한 것"만 남고 "사용자가
  AI 라고 *느낀* 것"이라는 관점 데이터를 못 얻는다 — 목적 미달.
- **제보 빈도 자동 사전 등록**: 사전(coach)은 첨삭 프롬프트에도 주입된다 — 검수 없는 승격은
  오염을 두 도구로 번지게 한다. [사전 등록]은 폼 채우기까지만.
- **인라인 펼침형 위젯**: sojae 가 100svh 앱셸이라 인라인 블록이 채팅을 잠식. 바텀시트
  (waitlist.js 패턴) + 페이지별 티저 한 줄로 통일.
- **크레딧 차감형**: 문턱이 생겨 수집이 죽는다. 무료 + (300자·하루 3회) 이중 상한이 원가 방어.

## 구조 요약

```
티저(quickfix.js, 3곳: answers·killer 입력·sojae compact)
  → 바텀시트: [로그인 확인] → [프로브 게이트: features 'quickfix' + quickfix_table]
  → 입력(300자) → ai-killer 함수 mode:'quickfix'
       Haiku 4.5 구조화 출력 {fixed, spotted[]} · coach 사전 주입 · 자기 출력 재검사
       spotted 는 원문 includes 검증 후 expression_reports 저장(하루 3회, 서울 자정)
  → 결과: 지금/이렇게 + 짚은 표현 + 퍼널 링크(KILL AI·첨삭)
admin '감점 사전' 탭 '회원 제보': 최근 500건 브라우저 집계 → 빈도 순위 → [사전 등록](폼 채우기)
```

서버를 ai-killer 분기로 둔 이유는 polish 와 동일 — 인증·사전 로드·프롬프트 재료가 같아서
별 파일이면 사전이 바뀔 때마다 두 벌을 고친다. 구버전 오차감(3크레딧) 함정도 polish 의
프로브 게이트 패턴을 그대로 물려받아 막는다.

## 검증 (2026-07-31 실측, 375px 하네스)

- 문법: `node --check quickfix.js` + 4개 페이지 인라인 JS `new Function` + 함수 esbuild 파싱 통과.
- 티저 335×68(2줄, keep-all)·compact 44px — 터치 44px+ 충족, 가로 넘침 없음.
- 시트: 배경막 첫 프레임부터 불투명(opacity 1) · textarea 16px(iOS 줌 방지) · 제출 52px ·
  고지 12px · 결과 뷰(지금/이렇게·spotted 2건·괄호 빈칸 강조·잔여 횟수·48px 액션 2개) 렌더 확인 ·
  퍼널 링크 자기 페이지 제외 동작 · 배경 탭 닫힘 확인.
