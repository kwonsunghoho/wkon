# AI킬러 — 자소서·답변의 'AI 문체' 검사 및 교정

> 2026-07-24 오너가 확정한 설계. 원본은 Claude Code 밖 대화창에 있어 세션 기록에 남지
> 않았고, 오너가 붙여준 내용을 그대로 옮긴다. **앞으로 이 문서가 소스오브트루스.**

## 무엇인가

학생(회원)이 자소서·면접 답변을 넣으면 **AI 같은 문체를 잡아내고 교정**해 주는 도구.
브리핑룸(`briefing.html`) 카드로 들어간다.

- **대상**: 회원(학생)
- **위치**: 브리핑룸 — 현재 카드 3장(항공 뉴스 / 소재 발굴 / 답변노트) + 숨김 1장(실전 모의면접) 옆
- **과금**: 무료 2회, 이후 10회 9,900원 충전

## 만드는 순서 (6단계)

| 단계 | 내용 | 필요한 것 |
|---|---|---|
| ① 페이지 + 즉시 검사 | 시안대로 화면 구성. 상투어·정형구조·구체성 밑줄을 **브라우저 안 규칙**으로 구현 | 없음 — 바로 시작 가능 |
| ② 저장 그릇 | 검사 기록 테이블(회원 계정에 묶어 저장), 동의 문구, 개인정보처리방침 갱신 | 오너: 마이그레이션 실행 + 방침 승인 |
| ③ AI 분석 중계 | Supabase Edge Function: 로그인 확인 → **잔여 횟수 서버 검증·차감** → Claude 호출 → 결과 저장. 키는 Secrets | 오너: Anthropic 계정 + 카드 + 월 한도 |
| ④ 횟수·결제 | 무료 2회, 10회 9,900원. **모의면접 응시권의 계좌이체 확인 방식 그대로 재사용** | 없음 |
| ⑤ 말투 조련 + 실전 검증 | 아래 4겹 고삐. 진짜 답변 20~30건 돌려 연구진 검수 → 반영 반복 | 오너: 자료 + 연구진 검수 |
| ⑥ 배포 | 브리핑룸 카드 추가. 비교 통계는 숨김으로 시작 | 없음 |

①②는 자료 없이 시작 가능 — 자료 모으는 동안 병행한다.

## 오너가 줄 자료 3종

1. **감점 표현 목록(제일 중요)** — 연구진에게 "면접에서 들으면 속으로 한숨 쉬는 표현" 20~50개.
   형식 자유(카톡 나열도 OK). 가능하면 각각 "왜 별로인지" 한 줄.
2. **실제 첨삭 자료** — 학생 답변 원문 + 연구진 첨삭 코멘트. 10건이어도 충분. 개인정보 제거.
   ⚠️ 첨삭 '내용'만이 아니라 **첨삭 '말투'의 원본**이라 가장 값지다(아래 ① 고삐).
3. **좋은 답변 예시 3~5개** — 합격생 답변 또는 연구진이 "잘 썼다" 하는 것. 교정 방향의 기준.

## ⚠️ 결과에서 AI 냄새 빼기 — 4겹 고삐 (이 제품의 생명줄)

AI 티를 잡는 도구가 AI 티 나는 말투로 지적하면 그 자리에서 신뢰가 죽는다.

1. **말투의 원본 = 연구진의 실제 첨삭 문장.**
   ⚠️ **"자연스럽게 써"라고 지시하지 말 것 — 그 지시 자체가 AI스러운 결과를 낳는다.**
   대신 연구진이 실제로 학생에게 썼던 첨삭 문장을 통째로 보여주고 **"이 사람처럼 써라"**.
   지시가 아니라 흉내. 흉내가 지시보다 정확하다. (오너 말투 재현 작업에서 검증된 방식 —
   `anthropic-skills:monc-voice` 스킬과 같은 원리.)
2. **자유 작문 공간 자체를 없앤다.** AI 티는 길게 자유작문할 때 난다(인사말·"물론입니다!"·
   장황한 맺음말). 결과를 문장이 아니라 **정해진 칸**으로 받는다:
   `[걸린 표현 / 왜(1문장) / 고치기(1문장)]`. AI는 칸만 채우고 화면 틀은 우리가 그린다.
   낄 자리가 없으면 티도 못 낸다.
3. **AI킬러가 자기 출력도 킬한다.** 우리가 만든 상투어 사전("다양한", 첫째/둘째,
   "~하시길 바랍니다")을 **AI가 쓴 결과 문장에도 똑같이 돌려** 걸리면 다시 쓰게 한다.
   학생 답변을 재는 잣대로 자기 말도 재는 것 — 도구의 철학과도 맞는다.
4. **출시 전 사람 검수 2~3바퀴.** 실제 답변 20~30건 → 연구진이 "내가 안 할 말" 표시 →
   반영 → 재실행. 출시 후에도 저장된 검사 기록을 훑어 이상한 말투를 고친다
   (데이터를 모으는 이유가 하나 더 생긴다).
