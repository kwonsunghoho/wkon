## 무엇인가

학생(회원)이 자소서·면접 답변을 넣으면 **AI 같은 문체를 잡아내고 교정**해 주는 도구.
브리핑룸(`briefing.html`) 카드로 들어간다. 사용 감각은 띄어쓰기 검사기 — 글을 넣으면
문제 자리에 밑줄이 그어지고 옆에 "왜 별로인지 / 어떻게 고칠지"가 붙는다.

- **대상**: 회원(학생) — **로그인 필수**
- **위치**: 브리핑룸 — 현재 카드 3장(항공 뉴스 / 소재 발굴 / 답변노트) + 숨김 1장(실전 모의면접) 옆
- **과금**: 무료 2회, 이후 10회 9,900원 충전

### ⚠️ 왜 규칙 검사까지 서버인가 (결정 3)

원 확정본 ①단계는 "브라우저 안 규칙"이었다. 결정 2(검사 자체가 1회 차감)와 함께 놓으면
성립하지 않는다:

1. **차감을 브라우저가 신고하는 구조**가 되어 F12로 우회된다.
2. 더 중요하게, **연구진 감점 표현 목록 20~50개가 통째로 공개**된다. 이 목록이 이 도구의

①단계를 단독 배포할 수 없다는 것 — ①은 ③과 함께 나간다.

## 판정 엔진 — 무엇을 'AI스럽다'고 잡는가

### 핵심 분업: 자리는 규칙이 찍고, 말은 AI가 한다

규칙이 밑줄 위치를 확정한 뒤, AI는 **그 자리에 대해서만** 칸을 채운다.
AI가 자리까지 고르게 두면 없는 걸 지어내고, 4겹 고삐 ②(자유 작문 공간 제거)가 깨진다.

### 4종

| 종류 | 잡는 것 | 예 |
|---|---|---|
| **상투어** | 서버 사전 2단 — ⑴ 연구진 감점 표현(오너 자료 1) ⑵ 일반 AI 상투어 | "다양한 경험", "역량을 발휘", "~을 통해", "최선을 다하겠습니다", "소중한 경험이 되었습니다" |
| **정형 구조** | 첫째·둘째·셋째 나열, 접속부사 과다(또한/더불어/나아가), **문장 길이가 지나치게 균일**, 모든 문장이 같은 어미 | 문장 길이 표준편차가 임계 이하면 걸린다 — 사람 글과 AI 글의 가장 뚜렷한 차이 |
| **구체성 결여** | 숫자·고유명사·시간·장소가 하나도 없는 문단 (밑줄이 아니라 **문단 단위 지적**) | "많은 손님을 응대하며" → 몇 명? 어디서? 언제? |
| **문맥** | 위 셋에 안 걸리지만 전형적인 자리. **AI가 추가로 최대 3곳까지 지목** | "어릴 적부터 하늘을 동경해왔습니다" |

'문맥'만 예외적으로 AI에게 지목 권한을 주되, 출력 칸 형식은 나머지와 동일하게 강제한다.

### 결과 칸 (고정 형식)

```
[걸린 표현] / 왜 그런지 1문장 / 어떻게 고칠지 1문장
```

AI는 이 칸만 채운다. 인사말·맺음말·요약이 들어갈 자리가 마크업에 없다.

### 등급 (결정 5)

절대 개수는 그대로 보여주되 **등급은 100자당 밀도로 판정**한다 — 200자 답변의 3곳과
1000자 자소서의 3곳은 전혀 다르기 때문.

| 밀도(100자당) | 등급 |
|---|---|
| < 1.0 | 사람 같음 |
| 1.0 ~ 2.5 | 조금 티남 |
| > 2.5 | AI 티 많이 남 |

임계값은 초안이며 ⑤단계 연구진 검수에서 실제 답변으로 조정한다.

### 입력 제한

- **최소 100자** — 그보다 짧으면 밀도 판정이 무의미하다(한 곳만 걸려도 등급이 튄다)
- **최대 3000자** — 자소서 1문항 + 여유. AI 원가 상한이기도 하다

## 화면 (`ai-killer.html`)

375px 우선. 세로 한 줄 구성:

1. **입력** — 붙여넣기 textarea + `답변노트에서 불러오기` 버튼(저장된 답변 목록 → 선택)
2. **검사 버튼** — 잔여 횟수 표시. 0회면 충전 안내

6. **저장** — 답변노트에서 불러온 글이면 그 답변에 결과를 붙여 저장

밑줄 탭 → 해당 카드로 스크롤, 카드 탭 → 해당 밑줄로 스크롤(양방향).

## ⚠️ 결과에서 AI 냄새 빼기 — 4겹 고삐 (이 제품의 생명줄)

AI 티를 잡는 도구가 AI 티 나는 말투로 지적하면 그 자리에서 신뢰가 죽는다.

1. **말투의 원본 = 연구진의 실제 첨삭 문장.**
   ⚠️ **"자연스럽게 써"라고 지시하지 말 것 — 그 지시 자체가 AI스러운 결과를 낳는다.**
   대신 연구진이 실제로 학생에게 썼던 첨삭 문장을 통째로 보여주고 **"이 사람처럼 써라"**.
   지시가 아니라 흉내. 흉내가 지시보다 정확하다. (오너 말투 재현 작업에서 검증된 방식 —
   `anthropic-skills:monc-voice` 스킬과 같은 원리.)
2. **자유 작문 공간 자체를 없앤다.** AI 티는 길게 자유작문할 때 난다(인사말·"물론입니다!"·
   장황한 맺음말). 결과를 문장이 아니라 **정해진 칸**으로 받는다:
   `[걸린 표현 / 왜(1문장) / 고치기(1문장)]`. AI는 칸만 채우고 화면 틀은 우리가 그린다.
   낄 자리가 없으면 티도 못 낸다.
3. **AI킬러가 자기 출력도 킬한다.** 우리가 만든 상투어 사전("다양한", 첫째/둘째,
   "~하시길 바랍니다")을 **AI가 쓴 결과 문장에도 똑같이 돌려** 걸리면 다시 쓰게 한다.
   학생 답변을 재는 잣대로 자기 말도 재는 것 — 도구의 철학과도 맞는다.
4. **출시 전 사람 검수 2~3바퀴.** 실제 답변 20~30건 → 연구진이 "내가 안 할 말" 표시 →
   반영 → 재실행. 출시 후에도 저장된 검사 기록을 훑어 이상한 말투를 고친다
   (데이터를 모으는 이유가 하나 더 생긴다).
