## 코스 4종 — 내용

문구는 구현에서 다듬되 구성·링크는 아래가 기준. 시간 줄 값은 제안값 — 오너 검수에서 조정.

| 코스(코드) | 카드 질문 | 스텝 | 링크 | 시간 줄 |
|---|---|---|---|---|
| 비기너(beginner) | 승무원 준비가 처음이에요? | ① 답변 소재 발굴(세 번 해 보기) ② 필수 기출 하루 한 개 ③ 초급 기출 준비(소재 문제 초급) | sojae / programs / sojae | 하루 10~15분 |
| 실전(practical) | 면접이 당장 코앞이라면? | ① 답변 첨삭 ② 지원 항공사 뉴스 ③ 고급·심화 기출 | polish / news / sojae | 하루 15~20분 |
| 스퍼트(spurt) | 자소서·영상면접 준비가 시급? | ① 보신각·영합각 챌린지(모집 일정 보기) ② AI킬러로 자소서 다듬기 | challenges / ai-killer | 챌린지 기간 집중 |
| 데일리(daily) | 루틴을 잃고 싶지 않다면? | ① 뉴스 스크랩 ② 필수 기출 하루 한 개 | news / programs | 하루 5~10분 |

- ⚠️ 챌린지 스텝은 **모집 여부를 단정하지 않는다** — challenges.html 로 보내고 문구는 중립. 챌린지는 모집 0인 기간이 있다(nav 펄스 점을 뗀 이유와 같다).
- ⚠️ 필수 기출은 미오픈(기출 30 미입력) — "한달간 30개" 같은 약속 문구는 **상품 오픈 뒤에** 넣는다.
- 초급·고급 기출 스텝의 목적지는 `sojae.html` 그대로(난이도 고르는 화면이 먼저다) — 난이도 딥링크 파라미터를 새로 만들지 않는다. 난이도 안내는 스텝 설명 문장으로만.

## 화면 A — 코스 선택 전 (비회원 · 코스 미선택 회원 공통)

1. 히어로 — 지금 그대로(MONC NOTE / 승준노트 / 부제).
2. "연구진이 추천하는 코스예요!" — 코스 카드 4장 2×2. 카드 = 질문 밴드(틴트, 선택 시 네이비 + 흰 글씨) + 사진 + 코스명. 카드는 실제 `<button>` (div+click 금지 — 포커스·키보드 원칙).
3. **코스 상세 패널은 1개를 재사용** — 기본은 비기너, 카드를 누르면 패널 내용이 그 코스로 바뀐다. 코스 4개를 세로로 다 나열하지 않는다(모바일 길이 통제 — 오너 목업 2장째의 Q&A 나열을 이 방식으로 대체, 시안으로 승인). 내용: 코스명 · 질문 · 스텝 목록(각 스텝이 도구 링크) · 시간 줄 · [이 코스로 시작하기] CTA · "코스는 계정에 저장돼요 · 언제든 바꿀 수 있어요".
4. "내 입맛대로 골라서 준비해요" — 서클 6개: 뉴스 스크랩 · 소재 발굴 · 답변 첨삭 · AI킬러 · 필수 기출 · 나만의 노트(목업 5개에 노트 추가 — 오너 무이의). 도구 직행 담당.
5. 무료 맛보기(`#quickfix-mount`) — 지금 그대로 유지.

## 화면 B — 코스 선택 후 (로그인 + members.course 있음)

- 히어로 대신 **개인화 헤더**: "OO 님은 '비기너 코스'를 선택하셨어요." + 기록 칩 3개(답변 N · 대화 중 N · 스크랩 N) + "마이페이지에서 자세히 →". eyebrow(MONC NOTE)는 유지.
- **'오늘 이어서' 카드**: 내 코스 스텝 목록(링크) + CTA + 오른쪽 위 '코스 바꾸기'. CTA 는 코스별 대표 도구 **고정**: 비기너=소재 발굴 / 실전=답변 첨삭 / 스퍼트=AI킬러(챌린지는 모집 기간 문제로 CTA 부적합) / 데일리=뉴스 스크랩.
- 그 아래는 A와 동일(서클 · 무료 맛보기).
- '코스 바꾸기' = A 의 코스 선택 뷰를 다시 그린다. 저장된 코스는 **새 코스의 [시작하기]를 누를 때만** 바뀐다(안 고르고 떠나면 기존 유지).
- 숫자 정의: 답변 = `answers` 내 것 count / 대화 중 = 마이페이지 '대화 중' 줄과 같은 원장·같은 제외 규칙(`discovery_sessions` stage≠done, `answers` 에 행 있는 문제 제외 — mypage 로직 재사용) / 스크랩 = 뉴스 스크랩 count.
- ⚠️ **문장은 사이트가 아는 사실만**(mypage 규칙과 동일) — "오늘 아직 안 했어요" 같은 단정 금지. CTA 도 "오늘 이어서: 소재 발굴" 권유형.

## 데이터·저장

- 마이그레이션(레포에 파일로 두고, 본문은 대화창 ```sql 로 전달):
  `alter table public.members add column if not exists course text check (course in ('beginner','practical','spurt','daily') or course is null);`
- 읽기: 이 페이지의 자기 행 조회는 `select('*')`(미적용 환경 400 방지). **공용 `getMyProfile()` 셀렉트에 `course` 를 넣지 않는다**(major·agreed_at 전례).
- 쓰기: 본인 행 update. members 에 본인 UPDATE RLS 정책이 있는지 구현 때 확인 — 없으면 정책 마이그레이션을 같이 쓴다.
- 미적용 degrade: update 실패 시 B 로 전환하지 않고 "지금은 저장이 안 돼요. 잠시 뒤 다시 시도해 주세요" 안내(조용한 무시 금지, 단정 금지).
- 저장 성공 → `location.reload()` 로 B 진입(상태 분기 단순화 — bfcache 통째 reload 페이지라 부작용 없음).
- 비로그인이 [시작하기] → sessionStorage `monc_pending_course` 에 코스 코드 저장 후 `login.html?returnTo=briefing.html` → 복귀 시 자동 저장하고 pending 키 삭제 → B. (sessionStorage 고정 — 공용 기기 규칙.)

## 폐지·이관 (구현 시 briefing.md 에 기록)

- 폐지: 루트맵 룰렛(`.d-route`) · 매거진 목차 6줄(`.ix-item`) · 강조 3자리(01 판 · 06 소인 · 03 처음 추천 배지). 코스 카드 + 상세 패널이 대체한다.
- '처음 추천'의 역할은 **비기너 코스가 첫 카드 + 기본 패널**인 것으로 승계.
- rehearsal 숨김 행 — 삭제. 출시 때 서클·해당 코스 스텝에 추가(implementation-status 에 메모 이관).
- 유지: quickfix mount · bfcache 통째 reload + `scroll-keep.js`(입력값 없는 화면) · og/title 3종 동일 · 인앱 배너(`inapp.js`) · nav 는 `nav.js` 공용 — `BRIEFING_SUB` 도구 목록은 서클 6개와 같은 구성으로 유지.
- ⚠️ 여전히 금지: 코스·도구 카드에 회원별 상태 문구('첫 1회 무료' 등) · 근거 없는 표시('인기'·'NEW').

## 사진

- 4장 오너 제공 대기(목업에 쓴 스톡 그대로 가능). 받으면 webp 변환 + `loading="lazy"` + 카드 크기에 맞는 해상도(전송량 예산).
- 제공 전에도 배포 가능: 사진 영역은 틴트 배경으로 성립하고, 사진은 있으면 얹는다.

## 검증 계획

- 375px 실측(A/B 두 상태) + 320px 넘침 + 데스크톱 정렬.
- 로그인 상태는 스텁 하네스(mypage `_mypage-preview` 방식의 `_tmp` 파일)로 A/B 전환 · pending 복귀 · 저장 실패 degrade 재현(검증 후 삭제).
