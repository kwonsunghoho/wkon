# 첨삭 결과 화면 분량 전환 + 'N초 버전' — 설계 (2026-08-22)

오너 요청: "답변첨삭에서 길이를 선택하잖아? 결과물이 나오는 곳에서도 다른 길이도 선택해서
바로 볼 수 있게 했으면 좋겠는데? 크레딧을 사용해서" + "분량별 결과 품질도 다뤄야겠네 이거 할 때 같이".

## 오너 확정 사항

1. **이미 받아 본 분량은 저장된 결과를 다시 보여준다(차감 없음). 새 분량만 10크레딧.**
   같은 글·같은 분량·같은 지시면 한 번 더 돌려도 수준은 같고 표현만 달라진다 — 돈을 더 내도
   좋아지는 구조가 아니라서.
2. **분량을 고르면 'N초 버전' 한 덩어리를 더 준다(A안).** 지금 구조(원문 문장 → 고친 문장)는
   "20초면 이 답변이 통째로 어떻게 되는지"를 보여줄 자리가 없어, 학생이 조각을 모아 스스로
   조립해야 했다. 분량 문제의 핵심은 어느 문장을 빼고 남은 걸 어떻게 잇느냐다.

## 범위

- `polish.html` 결과 화면: 분량 버튼 줄 + 'N초 버전' 카드 + 재첨삭 흐름.
- `supabase/functions/ai-killer/index.ts` `mode:'polish'`: 출력 칸 둘 추가 + 분량 프롬프트 강화.
- 문서: `docs/notes/polish.md` · `docs/notes/implementation-status.md`.
- **범위 밖**: 자소서 분량(글자 수의 세계 — 별도), `answers.html` 이력 목록의 'N초' 꼬리표(후속),
  마이그레이션(없음 — 전부 `answer_polishes.result` jsonb 안).

## 화면(polish.html)

### 결과 머리 아래 분량 줄 `#rsLen`

- 버튼: 자유·20초·30초·40초. 입력 화면 `#lenRow` 와 같은 `.in-kind` 문법·같은 터치 규격(44px+).
- 현재 보고 있는 리포트의 분량이 `.on`(aria-pressed). 자유 리포트면 '자유'가 on.
- 버튼마다 **값에 이름표**를 붙인다(design-principles '값에는 그것이 무엇인지'):
  - 이미 받은 분량 → 작은 보조 글자 `다시 보기`(무차감).
  - 아직 없는 분량 → `10크레딧`(`polishCost()` 값 — 숫자 하드코딩 금지).
- 노출 조건 둘 다: ① 리포트의 글 종류가 면접 답변(`_kind==='interview'`) ② 서버 features 에
  `polish_length_version` 이 있다(프로브 게이트 — 구버전 함수는 N초 버전 칸을 안 돌려줘 "눌렀는데
  똑같다"가 된다). 입력 화면 `#lenRow` 의 게이트(`polish_length`)는 그대로 둔다.
- 캡션 한 줄: "다른 분량으로도 볼 수 있어요 — 이미 받은 분량은 크레딧이 안 나가요".

### 누르면

- **받은 게 있으면** 그 리포트를 `showResult()` 로 즉시 그린다(서버 호출 없음). 스크롤은 머리로.
- **없으면 재첨삭**: 같은 원문(`_lastText`)·문항·항공사·`answerId`·글 종류에 `targetSec` 만 새 값으로
  서버 호출. 서버 차감 키는 기존 `${answer}#p${prev}` 그대로 — 새 분량 = 새 첨삭 = 10크레딧.
  - 대기: 결과 화면 안 `#rsWait` 에 입력 화면과 같은 4단계 표시(`startWait(container)` 로 대상만
    바꿔 재사용). 대기 중 분량 버튼 전부 `disabled`, '새 첨삭' 버튼도 막는다.
  - 성공: 새 리포트로 갈아 그린다. `_byLen[sec]` 캐시에 넣는다. 잔액 새로고침.
  - 실패: `#resNotice` 에 warn. `no_credit` 이면 "충전하러 가기" 버튼 — 입력 화면으로 돌아가며
    `#chargeBox` 를 연다(충전함은 입력 화면에만 있다 — 복제하지 않는다).
  - 재첨삭 중 뒤로가기·새로고침: 입력값 없는 화면이 아니므로 기존 규칙(버튼만 복원)을 따른다.

### '이미 받은 분량' 판정

- 세션 캐시 `_byLen = { [sec]: resultObj }` — 이번 방문에서 받은 리포트.
- 저장분: `showResult()` 뒤 `answerId` 가 있으면 `answer_polishes` 에서
  `answer_id = _answerId` 행을 `created_at desc` 로 받아, **`content` 가 지금 리포트 원문과 정확히
  같은 행만** 분량(`result.target_sec`, 없으면 0)별로 가장 최근 것 하나씩 `_byLen` 에 채운다.
  (원문이 한 글자라도 다르면 다른 글 — 옛 글의 20초 버전을 지금 글의 것처럼 보여주면 안 된다.)
- `?polish=` 이력 복원 진입에서도 같은 흐름 — 그 리포트의 `answer_id`·`content` 기준.
- 테이블 조회 실패(미적용·네트워크)면 캐시만으로 동작(전부 '10크레딧'으로 보임 — 서버가
  어차피 매번 차감하므로 거짓 무료 표시는 생기지 않는다).

### 'N초 버전' 카드 `#verSec`

- 자리: 분량 줄 바로 아래, '글 전체에서 고칠 방향' 위. 리포트에 `short_version` 이 있을 때만.
- 제목 `N초 버전 — 내 글로만 다시 구성` + 보조 `약 100~120자` 같은 환산 안내(서버 `target_chars`).
- 본문: `short_version` 그대로(`white-space:pre-wrap`). 괄호 빈칸은 원문 펼침과 같은 모양.
- 아래 '덜어낸 대목' 줄: `cuts` 각각 `quote`(원문 그대로) → `why` 한 문장. 0건이면 줄 자체 생략.
- 주의 문구: 기존 '고친 예시는 **방향**이에요…' 문구를 이 카드 아래에도 한 번 더(같은 문장).
- 복사 버튼은 두지 않는다(그대로 들고 가라는 신호가 된다 — '첨삭의 선').

## 서버(ai-killer `mode:'polish'`)

### 출력 스키마

- 분량이 있을 때만 쓰는 `POLISH_SCHEMA_LEN` = 기존 셋 + `short_version`(string) +
  `cuts`(array of `{quote, why}`) — 둘 다 required. 자유(0)면 기존 `POLISH_SCHEMA` 그대로
  (칸을 옵션으로 두지 않는다 — 구조화 출력은 required 로 못 박는 편이 안전하고, 자유 리포트에
  빈 칸을 싣지 않는다).
- 반환·저장(`answer_polishes.result` jsonb)에 `short_version`·`cuts`·`target_chars` 추가(`target_sec` 옆).
  컬럼 추가 없음.

### 프롬프트(분량 있을 때)

user 메시지(캐시 자리인 system 에는 넣지 않는다 — 기존 주석 유지)에 `[목표 분량]` 절을 확장한다.

- 환산: 기존 `POLISH_TARGET_CHARS`(20초 100~120자 / 30초 150~180자 / 40초 200~230자).
- **덜어내는 순서**(짧아질수록 남길 것): ① 질문에 대한 답 한 문장 ② 그걸 보여주는 행동·장면 하나
  ③ 그 결과·배운 것 한 문장. 먼저 빼는 것: 배경 설명·같은 말 반복·수식어·일화가 둘이면 하나.
- `short_version` 규칙: 학생 글에 있는 재료만(없는 숫자·일화 금지, 모자라면 괄호 빈칸), 학생의
  어휘·정서를 남긴다, 소리 내어 말하는 문장, 목표 글자 수 안, 인사말·맺음말 없음.
  **글이 이미 목표보다 짧으면 늘리지 마라** — 같은 분량에서 다듬은 버전을 주고 cuts 는 빈 배열.
- `cuts`: 덜어낸 대목 1~3개, `quote` 는 원문 **있는 그대로**, `why` 는 왜 빼도 되는지 한 문장(60자·'~요').
- `[할 일]` 끝 재고지(마지막 지시가 가장 세게 먹는다 — 2026-08-14b)에 위 셋을 한 줄씩 다시 못 박는다.

### 검증·재생성

- 자기 출력 재검사(상투어 사전)에 `short_version`·`cuts.why` 를 포함한다.
- `short_version` 길이가 환산 상한의 1.3배를 넘으면 `regenNote`("N자 안으로 다시") 로 **한 번** 재생성.
  그래도 넘치면 그대로 반환(실패·환급 아님 — 리포트 본체는 멀쩡하다). 로그만 남긴다.
- `cuts.quote` 가 원문에 없으면 그 항목만 버린다(서버 필터 — 화면이 없는 인용을 그리지 않게).

### 배포 표식

- `FN_VERSION` `2026-08-22a`, features 에 `polish_length_version` 추가(`polish_length` 는 유지).
- 배포는 오너 콘솔. 적용 여부는 프로브로 확인(implementation-status.md 갱신).
